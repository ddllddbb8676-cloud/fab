# FAB Observatory

혼자 둘러보는 대형 반도체 팹 3D 공간. 가로 120m × 세로 180m, 바닥에서 천장까지 5m. 18개 bay마다 10대씩 두 줄이 마주 보며, 총 장비 360대·로드포트 1,080개·OHT 36대가 배치되어 있습니다. 실제 특정 팹의 설계나 장비 사양을 재현한 도면은 아닙니다.

## 실행

Node.js가 설치된 Windows에서 이 폴더의 `열기.cmd`를 실행합니다. 처음 설치 시에는 터미널에서 `npm.cmd install`을 먼저 실행합니다.

또는 `npm.cmd start` 실행 후 http://127.0.0.1:4173 에 접속합니다. 이 개발 서버는 로컬 컴퓨터에서만 접속할 수 있습니다. 모바일 관람용 배포 주소는 https://fab-observatory.ddllddbb8676.chatgpt.site 이며 소유자 전용 접근을 유지합니다. 여러 사람 동시 관람·생산 시스템 연결 기능은 포함하지 않습니다.

## 관람

- 자동 산책: 방진복 캐릭터를 따라 장비열과 중앙 통로를 관람. 드래그로 시선 변경.
- 직접 걷기: 캐릭터 뒤의 원근 3인칭 카메라. 바닥 클릭·탭으로 장애물을 피해 이동, WASD·방향키·휴대폰 버튼으로 직접 이동. 드래그 회전, 휠·핀치로 거리 조절. 장비·외벽과 캐릭터·카메라 충돌 처리.
- 전체 보기: 천장과 외벽을 숨기고 위에서 관찰. 드래그로 회전, 휠이나 핀치로 확대.
- 장비 클릭: 공정 소개. 오른쪽 위 음표: 로컬에서 합성하는 공조 소리 켜기/끄기.
- 처음으로: 에어샤워부터 다시 입장. 첫 화면은 약 11초 동안 바람 → 양쪽 자동문 열림 → 캐릭터 입장으로 이어지며, 건너뛰기·Esc로 즉시 입장할 수 있습니다. 동작 줄이기 설정을 따릅니다.
- FOUP 반송 보기: 실제 정차 중인 차량의 로드포트 앞으로 이동. 분리·빈차 순환·재픽업·다른 bay 운반 관찰.
- 뒤쪽 통로 보기: 1.4m 후면 서비스 통로로 이동. 같은 열의 장비 옆 틈은 0.65m.
- OHT 시점: 실제 OHT 주행을 따라 관람하며 다른 차량으로 전환 가능. 사람이 OHT에 올라타는 모델은 아닙니다.

3D 형상·텍스처·배치는 모두 프로젝트 코드로 생성합니다. 외부 3D 모델·생성형 3D API·유료 에셋을 사용하지 않습니다. 글꼴만 Google Fonts에서 읽으며, 연결이 없어도 시스템 글꼴로 표시됩니다. Three.js는 설치한 로컬 패키지에서 로드합니다.

## 구조

- `src/main.js`: 미터 단위 공간, 장비·OHT 모형, 인스턴싱, 이동·충돌, 미니맵, 관람 모드.
- `src/layout.js`: 장비·로드포트·레일의 공통 좌표, 통로 치수, 충돌 경계와 산책 경로.
- `src/rail-network.js`: 전체 포트를 연결하는 단방향 간선·서비스 선로·둥근 분기.
- `src/network-transport.js`: 교차로 예약·차간 간격·FOUP의 연속 소유 상태 및 bay 간 반송.
- `src/avatar.js`, `src/explorer.js`: 방진복 캐릭터 보행과 추적/회전 카메라 및 모바일 조작.
- `src/walking.js`: 좁은 측면 통로를 포함한 경로 탐색과 충돌.
- `src/transport.js`: 이전 독립 루프의 회귀 테스트용 상태 모델; 현재 화면은 network-transport.js 사용.
- `tests/layout.test.mjs`: 배치·레일 정렬·통로·충돌·반송 연속성 검증. `npm.cmd test`로 실행.
- `docs/layout-references.md`: 논문·공식 영상 근거와 모델 설정값의 구분.
- `src/style.css`: 반응형 관람 UI.
- `server.mjs`: 외부 접속을 허용하지 않는 로컬 정적 서버.

OHT는 로드포트 위 서비스 선로와 4개의 종방향 간선을 통해 팹 전체를 이동합니다. 68개 교차·분기점과 104개 둥근 회전 연결이 있으며, 1,080개 포트가 단방향 그래프에서 서로 도달 가능합니다. 교차로를 예약하고 앞 차량과 간격을 유지합니다. 내려놓은 FOUP은 실제 포트에 남고 빈 차량이 돌아와 회수한 뒤 다른 bay로 운반합니다. 실물 생산 제어기와 피난·유지보수 기준을 검증한 건축 설계는 아닙니다.

앞쪽 작업·중앙 통로는 5.2m, 장비 뒤쪽 통로는 1.4m, 같은 열의 장비 측면 틈은 0.65m입니다. 후면 통로를 좁힌 뒤 18개 bay가 들어가도록 배치를 조정했으며, 홀 크기 120×180m와 층고 5m는 유지합니다. 캐릭터는 높이 1.66m, 최대 폭 약 0.585m입니다.

`npm.cmd test`는 배치·연결성·회전 연속성·1,200초 반송 진행·충돌 방지·좁은 통로 보행을 검사합니다. 실제 모바일 기기의 핀치 입력과 GPU 성능은 별도 확인이 필요합니다.

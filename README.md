# FAB Observatory

> 현재 운영 버전은 [fab.semitoon.com](https://fab.semitoon.com/)입니다. 아래 본문은 초기 관람 버전의 설명으로, 동시 접속·기록 유지·NPC 구성 등 일부 내용은 현재와 다릅니다.
> 2026-11-02 조이스틱 변경 전 저장 기준과 현재 기능은 [체크포인트 문서](docs/checkpoint-2026-11-02.md), 보류된 로그인 작업은 [TODO.json](TODO.json)을 확인하세요.
> 이후 적용된 조이스틱·이동 속도·시야 변경과 검증은 [조이스틱 배포 기록](docs/joystick-release-2026-11-02.md)에 있습니다. 기본 조작은 왼쪽 조이스틱 이동 + 화면 드래그 시점 변경이며 메뉴에서 바닥 터치 이동으로 전환할 수 있습니다.

혼자 둘러보는 대형 반도체 팹 3D 공간. 가로 120m × 세로 180m, 바닥에서 천장까지 5m. 18개 bay마다 10대씩 두 줄이 마주 보며, 총 장비 360대·로드포트 1,080개·OHT 36대가 배치되어 있습니다. 실제 특정 팹의 설계나 장비 사양을 재현한 도면은 아닙니다.

## 실행

Node.js가 설치된 Windows에서 이 폴더의 `열기.cmd`를 실행합니다. 처음 설치 시에는 터미널에서 `npm.cmd install`을 먼저 실행합니다.

또는 `npm.cmd start` 실행 후 http://127.0.0.1:4173 에 접속합니다. 이 개발 서버는 로컬 컴퓨터에서만 접속할 수 있습니다. 모바일 관람용 배포 주소는 https://fab-observatory.ddllddbb8676.chatgpt.site 이며 소유자 전용 접근을 유지합니다. 여러 사람 동시 관람·생산 시스템 연결 기능은 포함하지 않습니다.

## 관람

기본 화면은 작은 메뉴 버튼과 현재 위치만 표시합니다. 오른쪽 위 메뉴에서 관람 방식·장비·설정을 선택하며, 지도는 필요할 때 펼칩니다. 메뉴 밖을 누르거나 Esc로 닫을 수 있습니다.

- 자동 산책: 현재 서 있는 자리에서 가까운 산책 경로로 걸어 합류합니다. 중지·재시작해도 위치가 유지되며, 드래그로 시선을 바꿉니다.
- 직접 걷기: 캐릭터 뒤의 원근 3인칭 카메라. 바닥 클릭·탭으로 장애물을 피해 이동합니다. 방향 패드와 키보드 이동은 사용하지 않습니다. 드래그 회전, 휠·핀치로 거리 조절. 장비·외벽과 캐릭터·카메라 충돌 처리.
- 전체 보기: 천장과 외벽을 숨기고 위에서 관찰. 드래그로 회전, 휠이나 핀치로 확대.
- 장비 클릭: 7자리 고유 코드, 종류, 공정, FAB·BAY·장비 순번과 로드포트 이름 표시. 화면을 처음 터치하거나 키보드를 누르면 로컬에서 합성하는 공조음이 시작되며, 오른쪽 위 공조 버튼으로 끄고 켭니다. 직접 끈 소리는 다른 조작으로 다시 켜지지 않습니다.
- 장비 목록: 360대·11개 장비군·35종류. 이름·코드·BAY 검색과 공정 필터를 지원하며, 항목을 누르면 해당 장비 앞으로 이동합니다.
- EMO: 모든 장비 전면의 빨간 버튼을 선택하면 현재 위치에서 앞으로 걸어가 손을 뻗고 0.75초 꾹 누른 뒤 폭발·파편·붕괴·연기 효과가 나타납니다. 이동·다른 관람 모드·도움말·입장 초기화는 누르기를 취소합니다. 파손 장비를 선택하거나 메뉴의 수리 목록에서 한 대를 골라 걸어가 5초간 망치질하며 조립합니다. 관람용 특수효과이며 새로고침하면 초기화됩니다.
- 휴식: 화면 아래의 앉기·눕기 버튼으로 현재 자리에서 쉽니다. 0.65m 장비 틈에서는 몸을 통로 방향으로 돌려 눕습니다. 바닥을 누르면 일어나 다시 걷습니다.
- OHT 탑승: 지나가는 빈 OHT를 누르면 앞 장비를 밟고 점프해 양손으로 매달립니다. 파손된 장비로는 탈 수 없습니다. 기존 화물은 떨어뜨리고 팹 전체를 순회하며, 내리기를 누르면 착지합니다. AI 캐릭터가 탄 차량은 다른 차량을 안내합니다.
- FOUP 놀이: 로드포트나 바닥의 FOUP을 눌러 집고, 다른 빈 로드포트를 누르면 내려놓습니다. 아래의 바닥에 놓기·던지기도 지원합니다. 이용자와 상주 캐릭터가 같은 FOUP 소유 상태를 공유하며 복제하지 않습니다.
- 소리: 맨 위의 효과음·공조음 버튼으로 각각 음소거합니다. 걷기·휴식·망치질·점프·착지·FOUP 조작 효과음이 나올 때 공조음을 32%로 낮췄다가 복귀합니다. 먼 캐릭터의 소리는 거리로 줄이고 22m 밖에서는 생략합니다. 폭발은 34m 범위이며 동시 효과음은 4개로 제한합니다.
- 상주 캐릭터: 각 팹 인스턴스에 AI 30명(FOUP 놀이 5, OHT 산책 5, 휴식 10, 수리 5, EMO 놀이 5)이 항상 존재합니다. 실제 접속자 수로 표시하지 않습니다. 형용사와 반도체 단어를 조합한 이름은 공백 포함 7자 이내입니다. 공용 형상 인스턴싱, 먼 모션 10fps, 가까운 모션 30fps, 프레임당 최대 한 경로 탐색으로 부하를 제한합니다. 사용자가 조작 중인 장비는 AI가 양보합니다.
- 처음으로: 에어샤워부터 다시 입장. 약 12.5초 동안 바람 → 양쪽 자동문 열림 → 캐릭터 입장 → 문 닫힘으로 이어집니다. 건너뛰기·Esc와 동작 줄이기 설정에서도 최종 문은 닫히고 캐릭터가 통과할 수 없습니다.
- FOUP 반송 보기: 캐릭터 위치를 유지한 채 로드포트·FOUP·OHT의 승강을 함께 보는 전용 시점으로 전환합니다. 한 차량을 계속 관찰하며, 모두 운반 중일 때는 실제 OHT와 FOUP을 따라가다 도착한 포트의 시점으로 바뀝니다.
- 뒤쪽 통로 보기: 1.4m 후면 서비스 통로로 이동. 같은 열의 장비 옆 틈은 0.65m.
- OHT 시점: 실제 OHT 주행을 따라 관람하며 다른 차량으로 전환 가능. 사람이 OHT에 올라타는 모델은 아닙니다.

3D 형상·텍스처·배치는 모두 프로젝트 코드로 생성합니다. 외부 3D 모델·생성형 3D API·유료 에셋을 사용하지 않습니다. 글꼴만 Google Fonts에서 읽으며, 연결이 없어도 시스템 글꼴로 표시됩니다. Three.js는 설치한 로컬 패키지에서 로드합니다.

## 구조

장비 ID는 `PHA0101`처럼 `공정 2 + FAB 1 + BAY 2 + 장비 순번 2`의 7자리입니다. PH 포토, ET 식각, CL 세정, CM CMP, CV 증착, ME 금속배선, DI 확산·산화, IM 이온주입, MT 계측, IN 검사, SO 소터를 사용합니다. FAB은 A, BAY는 01~18이며 BAY 안에서 A열 01~10, B열 11~20으로 부릅니다. 앞뒤 명판은 하나의 텍스처 아틀라스로 묶었습니다. 기능별 이름과 출처는 `docs/equipment-names.md`에 있습니다.

BAY 01·10은 포토, 06은 메탈, 15는 Cu 전용 세정으로 황색 면광원을 사용합니다. BAY 08은 일반 세정입니다. 숫자 BAY 이름과 용도는 별도 정보입니다. 면광원 4개와 위치별 백색광 감쇠로 장비·바닥·캐릭터에 빛을 비추며, 전체 보기에서는 지붕과 함께 조명을 끕니다. `src/bay-lighting.js`의 셰이더 훅은 고정된 Three.js 0.186.1에 맞췄습니다.

장비 목록의 용량 계산표는 `docs/capacity-plan.html`입니다. 공개 공부방 흐름의 319공정·54계측 지점에 처리량·호환성·샘플링 가정을 적용한 월 3만 장 신규 투입 계획치이며 실제 레시피 검증값은 아닙니다. 기준 259대와 선택 예비 8대를 구분합니다. 사용자 요청대로 공간 120×180×5m, 18개 BAY, 관람용 360대는 유지합니다. BAY 13은 열처리, 14는 증착, 16은 식각으로 재배정해 해당 공정군의 수량 비중을 늘렸습니다. 공정군별 수량 배분을 맞춘 것이며 개별 모형의 실제 레시피 적합성을 검증한 것은 아닙니다. `node scripts/calculate-capacity.mjs`로 저장된 원문 `data/dram-flow-2026-10-30.json`에서 보고서·정적 모델을 재생성합니다.

- `src/main.js`: 미터 단위 공간, 장비·OHT 모형, 인스턴싱, 이동·충돌, 미니맵, 관람 모드.
- `src/layout.js`: 장비·로드포트·레일의 공통 좌표, 통로 치수, 충돌 경계와 산책 경로.
- `src/rail-network.js`: 전체 포트를 연결하는 단방향 간선·서비스 선로·둥근 분기.
- `src/network-transport.js`: 교차로 예약·차간 간격·FOUP의 연속 소유 상태 및 bay 간 반송.
- `src/avatar.js`, `src/explorer.js`: 큰 둥근 후드와 점눈, 작은 마스크, 짧고 둥근 몸통에 자연스럽게 내려오는 팔을 가진 약 2.4등신 방진복 캐릭터. 공용 형상·재질을 사용하는 14개 Mesh·3,274개 삼각형이며 팔을 내려 다리와 반대로 흔들며 걷고, 두 관절 팔로 EMO에 손을 뻗습니다. 이동·드래그·줌은 프레임 간격에 맞춰 부드럽게 보간하고 카메라는 장애물에서 즉시 안쪽으로, 해제 후 천천히 원래 거리로 돌아갑니다.
- `src/view-controls.js`: 접힌 관람 메뉴·선택형 지도, 배경 클릭 차단, 열림/닫힘과 포커스 복귀.
- `src/spatial-batch.js`: 24m 셀 경계로 화면 밖 인스턴스를 제외하고 보이는 형상만 재질별 한 묶음으로 그립니다. 먼 장비의 작은 부속만 55m 기준으로 생략하며 장비 몸통·배치·레일은 유지합니다. 원본 인덱스를 보존해 EMO 파손·복구와 연결됩니다.
- `src/walking.js`: 좁은 측면 통로를 포함한 경로 탐색과 반경 0.295m 보행 충돌. 장비 몸체·돌출 로드포트·모니터대를 분리해 빈 공간을 보존합니다.
- `src/transport.js`: 이전 독립 루프의 회귀 테스트용 상태 모델; 현재 화면은 network-transport.js 사용.
- `tests/layout.test.mjs`: 배치·레일 정렬·통로·충돌·반송 연속성 검증. `npm.cmd test`로 실행.
- `docs/layout-references.md`: 논문·공식 영상 근거와 모델 설정값의 구분.
- `src/style.css`: 반응형 관람 UI.
- `server.mjs`: 외부 접속을 허용하지 않는 로컬 정적 서버.

OHT는 로드포트 위 서비스 선로와 4개의 종방향 간선을 통해 팹 전체를 이동합니다. 68개 교차·분기점과 104개 둥근 회전 연결이 있으며, 1,080개 포트가 단방향 그래프에서 서로 도달 가능합니다. 교차로를 예약하고 앞 차량과 간격을 유지합니다. 내려놓은 FOUP은 실제 포트에 남고 빈 차량이 돌아와 회수한 뒤 다른 bay로 운반합니다. 실물 생산 제어기와 피난·유지보수 기준을 검증한 건축 설계는 아닙니다.

앞쪽 작업·중앙 통로는 5.2m, 장비 뒤쪽 통로는 1.4m, 같은 열의 장비 측면 틈은 0.65m입니다. 후면 통로를 좁힌 뒤 18개 bay가 들어가도록 배치를 조정했으며, 홀 크기 120×180m와 층고 5m는 유지합니다. 캐릭터는 높이 1.44m이며 반경 0.295m 안에 맞춰 좁은 통로를 지날 수 있습니다. 다중 사용자 접속·원격 캐릭터 표시 기능은 아직 포함하지 않습니다.

바닥은 공용 환경맵으로 은은한 광택을 내며, 팹 전체를 다시 그리던 실시간 거울 반사는 사용하지 않습니다. 정적 행렬·미니맵 바탕은 재사용하고, 기기의 프레임 간격이 길어지면 렌더 해상도를 점진적으로 조절합니다. 진단값의 프레임 통계는 입장 중과 250ms를 넘는 일시 중단을 제외하므로 전체 성능 측정 대신 추세 확인용입니다.

`npm.cmd test`는 배치·연결성·회전 연속성·1,200초 반송 진행·충돌 방지·좁은 통로 보행을 검사합니다. 실제 모바일 기기의 핀치 입력과 GPU 성능은 별도 확인이 필요합니다.

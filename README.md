# FAB Observatory

혼자 둘러보는 대형 반도체 팹 3D 공간. 가로 120m × 세로 180m, 바닥에서 천장까지 5m. 장비 144대와 OHT 29대가 배치되어 있습니다. 실제 특정 팹의 설계나 장비 사양을 재현한 도면은 아닙니다.

## 실행

Node.js가 설치된 Windows에서 이 폴더의 `열기.cmd`를 실행합니다. 처음 설치 시에는 터미널에서 `npm.cmd install`을 먼저 실행합니다.

또는 `npm.cmd start` 실행 후 http://127.0.0.1:4173 에 접속합니다. 서버는 로컬 컴퓨터에서만 접속할 수 있습니다. 인터넷 공개, 계정, 외부 서버, 여러 사람 접속 기능은 포함하지 않습니다.

## 관람

- 자동 산책: 중앙 통로와 외곽 통로를 따라 이동. 드래그하면 시선 변경.
- 자유 이동: WASD 또는 방향키, Shift로 빠르게 이동, 드래그로 시선 변경. 장비와 외벽 충돌 방지. 휴대폰은 이동 버튼 제공.
- 전체 보기: 천장과 외벽을 숨기고 위에서 관찰. 드래그로 회전, 휠이나 핀치로 확대.
- 장비 클릭: 공정 소개. 오른쪽 위 음표: 로컬에서 합성하는 공조 소리 켜기/끄기.
- 처음으로: 시작 위치와 관람 상태 복원.

3D 형상·텍스처·배치는 모두 프로젝트 코드로 생성합니다. 외부 3D 모델·생성형 3D API·유료 에셋을 사용하지 않습니다. 글꼴만 Google Fonts에서 읽으며, 연결이 없어도 시스템 글꼴로 표시됩니다. Three.js는 설치한 로컬 패키지에서 로드합니다.

## 구조

- `src/main.js`: 미터 단위 공간, 장비·OHT 모형, 인스턴싱, 이동·충돌, 미니맵, 관람 모드.
- `src/style.css`: 반응형 관람 UI.
- `server.mjs`: 외부 접속을 허용하지 않는 로컬 정적 서버.

OHT 차량은 레일 방향과 길이 방향이 일치하며, 중앙 운반 공간과 FOUP을 분리했습니다. 하강 시 같은 FOUP이 내려오고 차량 내부 상부에서 나온 벨트와 상부 그리퍼가 연결됩니다. 캐릭터, 실제 장비 내부 공정, 실제 생산 제어는 구현하지 않습니다.

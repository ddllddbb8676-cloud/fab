```text
운영: https://fab.semitoon.com/

먼저 docs/HANDOFF-2026-11-02.md와 현재 Git 상태를 읽어줘.
조이스틱·빠른 이동·넓은 시야는 구현/배포/push를 마쳤고 지금 조작감은 마음에 들어.
꾸미기 상점·내 옷장·칩 보상·소급 지급·새 이름표까지 정식 적용했어.
NPC 기본템·미구매자 안내, 기존/신규 닉네임 무료 1회와 랭킹 연동도 적용했어. 무료 기회를 쓴 뒤에는 상점에서 1,000칩 닉네임 변경권을 구매해 다시 바꿀 수 있어. 변경권은 확정할 때 한 장 쓰고, 취소/재접속에도 보관돼.

합의한 보상은 파괴 5칩, 수리 3칩, FOUP 던지기 1칩, 실제 OHT 탑승 10초마다 1칩이야.
OHT는 내리면 남은 시간이 끝나. 17초 타면 1칩을 받고 남은 7초는 버려. 다음 탑승은 0초부터야. 이미 받은 칩은 유지해.
화면은 복잡하지 않게 하고, 현재 조이스틱과 기존 ID·닉네임·누적 기록·장비 파손 상태를 보존해줘.
닉네임 변경은 동일 ID에서 이름만 바꾸며 파괴/수리·칩·구매/착용은 유지해야 해. 부적절한 이름은 삭제 경고를 보여 주되 실제 조치는 추천 이름으로 교체만 해. 소유자 메뉴에 닉네임 관리가 있고, FAB짱 세미의 지정 이름은 유지해.
카카오·구글 로그인은 TODO.json에 보류해 둔 일이니 아직 시작하지 마.

docs/customization-decisions-2026-11-02.md도 읽어줘. 운영 게임에 전부 적용했고 별도 모바일 미리보기는 체험용으로 독립되어 있어.
기존 파괴 × 5 + 수리 × 3칩을 사용자별 최초 한 번 소급 지급하는 것으로 결정했어. 과거 FOUP/OHT는 소급하지 않아.
상점에서는 미구매 아이템도 시착하고, 내 옷장에서는 보유 아이템만 모아보고 착용할 수 있게 해줘. 1차 가격은 결정 문서 표와 같고 곰돌이 3,000/거북이 1,800이야. FAB짱 세미 한 ID만 서버 secret으로 무제한 권한을 설정했어. 실제 ID를 문서에 쓰지 마.
```

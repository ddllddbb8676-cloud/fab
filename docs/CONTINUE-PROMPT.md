# 새 대화에서 팹뿌 이어가기

최신 종합 인수인계는 [HANDOFF-2026-11-11.md](HANDOFF-2026-11-11.md)다. 이 파일의 아래 프롬프트를 새 대화에 붙여 넣는다. 이전 누적 프롬프트는 [원본 보관본](archive/CONTINUE-PROMPT-through-2026-11-10.md)에 그대로 남겨 두었다.

11/12 추가 작업: 주요 조작을 설명하는 90초 세로 영상과 구간별 재생 페이지.
제작·검증·결과 위치는 [조작 안내영상 문서](../scripts/fab-tutorial/README.md)를
확인한다. 게임 기능이나 서버를 변경한 작업은 아니다.
11/12 오후에는 실제 UI와 다른 버튼 재현 및 내레이션을 없애는 수정 요청이
추가됐다. 풉으로 서로 맞추기 6초 장면과 음성 없는 92초 음원은 준비했으나,
Work 브라우저 비활성으로 실제 UI 촬영과 수정 완성본 배포는 미완료다.
위 문서의 오후 수정 상태를 먼저 확인하고 기존 90초본을 최신 완료본으로
보고하지 않는다.

```text
팹뿌(FAB Observatory) 프로젝트를 이 대화에서 이어서 작업하자.

로컬: E:\개인비서\fab-observatory
GitHub: https://github.com/ddllddbb8676-cloud/fab
운영: https://fab.semitoon.com/
관리자: https://fab.semitoon.com/admin

먼저 docs/HANDOFF-2026-11-11.md를 끝까지 읽고, 내 새 요청에 해당하는 기능 문서와 실제 코드를 확인해줘. 필요하면 docs/archive/CONTINUE-PROMPT-through-2026-11-10.md에서 과거 상세 이력을 찾아줘. 옛 docs/HANDOFF-2026-11-02.md만 읽고 상점이나 구글 연결이 미구현이라고 판단하면 안 돼.

현재 Git 상태·브랜치·원격 변경을 확인하고 다른 변경을 보존해줘. 배포가 필요한 작업이면 현재 운영 버전과 복구 상태도 다시 확인해줘. 11/11 인계 당시 운영은 ef870166-cbfa-4829-8739-93764f7d3699였고, 마지막 완료 기능은 링크 공유 표지야. 과거 완료된 실행기·판매 집계·heartbeat를 다시 실행하지 마.

게임 이용에 지장을 주지 않는 것이 최우선이야. 기존 계정·닉네임·칩·보유품·파괴/수리 기록·구글 연결을 지키고, 분석을 게임 응답의 대기 조건으로 만들지 마. 운영자 권한은 기존 계정 인증으로만 확인하고 비밀값이나 개인 식별자를 출력·커밋하지 마.

최종 결정은 카메라 자동 회전 원복, 카트 끌기, 이모지 27개/9개씩, 대화 5글자, 입구 스토커 2대야. 구글 연결과 1,000칩 보상·관리자 전체 랭킹·이벤트·승인 아이템 19종·공유 표지는 이미 반영됐어. 카카오·앱스토어 출시는 보류이고 선택하지 않은 11종은 미출시야.

옛 통계와 테스트 결과는 날짜가 있는 과거 근거로만 사용해줘. 실제 iPhone·Threads 표시 검증을 했다고 추정하지 마. 새 요청을 구현할 때 필요한 검사를 하고, 완료한 코드·문서는 커밋과 push까지 마친 뒤 실제 배포 여부와 검증 한계를 짧게 알려줘.

문서를 읽었다는 이유만으로 재배포하거나 임의 기능·예약 작업을 시작하지 말고, 현재 상태를 짧게 확인한 다음 내가 주는 새 요청을 이어서 수행해줘. 반복 승인 질문이나 고정 팀 조직 없이 직접 협업해줘.
```

다른 PC에서는 저장소를 clone한 뒤 읽는다. 로컬 `outputs/`, `.wrangler/`, 인증 설정, 사용자 DB, 최종 광고 MP4는 Git에 포함되지 않는다. 필요한 권한·자료가 없는 경우 확인되지 않은 결과를 만들지 않는다.

## 접속과 표시

- 주소 `/admin`. 게임 메뉴에서 운영자에게만 `운영 현황` 링크를 표시한다. 기존 운영자 계정으로 같은 브라우저에서 연다.
- HTML과 `/api/admin/metrics` 모두 서버의 `FAB_OWNER_VISITOR_ID`와 기존 세션 쿠키를 검증한다. 닉네임이나 클라이언트 플래그로 권한을 부여하지 않는다.
- 현재 연결 계정, 최근 5분 활동 중인 연결 계정, 오늘 중복 제거 계정, 최고 동접을 표시한다. 운영자와 안전팀 역할의 실제 계정은 연결 현황에 포함하며 NPC와 검증 계정은 제외한다.
- 시간별 고유 계정, 최고/평균 동접과 파괴·수리·유료 아이템 구매 수를 수집한다. 최근 30일 중 기록 있는 날짜를 선택할 수 있다.
- 이동 또는 성공한 게임 조작을 활동으로 본다. 연결 heartbeat만으로 활동했다고 표시하지 않는다. 평균 동접은 서버가 관측한 실제 시간 기준이며 재시작 공백은 제외한다.
- 과거 시간대별 이력은 없으므로 새 수집 시작 이후만 표시한다. 결측값은 0으로 꾸미지 않는다. 고유 계정은 사람 수와 다르고 시간별 고유 수의 합은 하루 고유 수가 아니다.
- 꾸미기는 일반 계정의 저장된 유료 보유품 기준이다. 운영자·검증 계정·무료템·시착을 제외하고, 이름 변경권은 별도로 표시한다. 현재 가격 환산값은 과거 실제 소비 칩이나 매출이 아니다.

## 부담과 데이터 보존

- 별도 분석 서비스나 데이터베이스를 만들지 않고 기존 Durable Object의 별도 `metrics:v1:` 키를 쓴다.
- 기존 시작 시 프로필 읽기에서 집계 투영을 만들고 이후 저장의 차이만 반영한다. 관리자 새로고침은 프로필 전체를 다시 읽지 않는다.
- 시간별/일별 작은 묶음을 기본 1분마다 저장하고 마지막 연결 종료 시 추가 저장한다. 통계 쓰기에만 `allowUnconfirmed:true`를 사용한다. 프로필·칩의 기존 저장 보장은 유지한다.
- 현재 시간대/날짜의 중복 제거용 지문은 내부에만 보존한다. 완료된 구간에서는 지문을 제거하고 30일 이후 요약을 삭제한다. 구간별 고유 계정이 4,096개를 넘으면 하한 표시로 전환한다.
- 화면을 보고 있을 때만 1분마다 JSON을 읽는다. 관리자 조회는 게임 참가자를 만들지 않는다.
- 통계에는 마지막 저장 이후 최대 약 1분의 수집 유실 가능성이 있다. 게임 기록 자체의 손실을 뜻하지 않는다. 원시 좌표/기기/국가/IP 로그와 전체 사용자 명단은 반환하지 않는다.
- 실제 추가 과금은 요금제·방 가동 시간·저장 크기에 달려 있다. 무료라고 단정하지 않는다. 구현은 매 프레임 저장 방식이나 관리자 조회마다 전체 프로필 스캔하는 방식보다 적은 작업을 수행한다.

# 운영자 전체 랭킹

## 동작

- 게임 메뉴 → 운영 현황(`/admin`) → 전체 랭킹. 접속 닉네임 위에도 바로가기 링크가 있다.
- 저장된 실제 캐릭터를 누적 파괴 수 내림차순으로 50개씩 표시한다. 동률은 기존 TOP5와 같은 내부 ID 순서로 고정하며 순위는 1, 2, 3…으로 매긴다. NPC와 설정된 검증 계정만 제외하고 운영자·오프라인·파괴 0 계정도 포함한다.
- 열: 랭킹, 아이디·닉네임, 부순 장비 수, 고친 장비 수, 가입일, 접속 횟수, 구글 연동 여부. 안전팀 역할의 임시 이름 대신 본래 게임 닉네임을 보여준다.
- 모바일에서는 표 내부를 좌우/아래로 스크롤한다. 순위와 닉네임, 열 제목은 고정하고 이전/다음 50명 버튼을 제공한다. 패널을 펼쳤을 때만 조회하며 보이는 탭에서 1분마다 현재 페이지를 갱신한다.

## 기록의 의미와 한계

- 가입일은 확인 가능한 최초 게임 접속일(KST)이다. 기존 성장 통계에 신규 계정 생성 당시 날짜가 남아 있으면 복구하며, 오래된 계정의 알 수 없는 날짜는 `미확인`으로 표시한다. 관측 시작일을 과거 가입일로 꾸미지 않는다.
- 접속 횟수는 이 기능 적용 이후의 입장 세션 수다. 이전 횟수는 없으므로 소급 집계하지 않는다. 접속 유지 중 재연결과 연결 종료 후 30분 이내 재접속은 한 번으로 세며, 30분 이상 지난 복귀는 추가한다. 서버 재시작으로 복구한 소켓은 중복 집계하지 않는다.
- 신규 캐릭터의 가입일과 접속 횟수는 기존 게임 프로필과 분리한 `admin:visits:v1:`에 보존한다. 계정 초기화 시 해당 통계도 삭제한다. 통계 저장 실패는 게임 입장이나 칩/장비 기록 저장을 막지 않으며 마지막 저장 이후 약 1분의 관측 누락 가능성이 있다.
- 구글 연동은 현재 연결 테이블에서 확인한 불리언이다. 조회 오류는 `미연동`으로 단정하지 않고 `확인 불가`로 표시한다.

## 권한과 부담

- HTML과 `GET /api/admin/rankings?page=N`은 기존 운영자 쿠키 및 구글로 복원된 운영자 세션을 검사한다. 일반 계정·익명 요청은 403이며 외부에 닉네임으로 권한을 부여하지 않는다. 응답은 private/no-store다.
- 응답에는 요청한 7개 필드만 포함하며 내부 ID·구글 이메일/식별자·쿠키·지갑·좌표는 반환하지 않는다. trusted DO binding의 내부 `rankingReport`와 가입일 조회 RPC는 공개 URL이 아니다.
- 기존 시작 시 프로필 조회의 observer에서 작은 순위 투영을 만든다. 페이지를 넘길 때 전체 저장 프로필을 재조회하지 않는다. 구글 연결은 요청 페이지의 최대 50개만 한 번에 읽는다. 가입일 조회는 별도 분석 DO에 최대 50개/1.5초로 제한한다.
- 메타데이터는 기존 1분 통계 저장 주기에 합치며 이동 프레임마다 저장하지 않는다. DB/서비스/상용 라이브러리나 예약 작업을 추가하지 않는다. 정적 게임 파일은 빌드 스크립트 변경으로 모듈 버전만 함께 갱신되며 게임 동작 소스는 변경하지 않는다.

- 전체 테스트 699개 통과, 기존 선택 검사 1개 생략. 관련 45개 통과/선택 1개 생략. 권한, 페이지 경계, 동률, 오래된 가입일, 재접속 중복, 저장 실패·중첩 쓰기·복원, 문자열 안전 출력, 접근권한 상실 후 응답 차단을 검사한다.
- 격리한 실제 Wrangler에서 123개 가상 프로필 중 검증 계정을 제외한 122개를 50/50/22로 조회했다. 운영자/오프라인 포함, 구글 연동 표시, 과거 신규 날짜 복구, WS/HTTPS 입장·감정표현, 조회 전후 프로필 해시 보존을 확인했다.

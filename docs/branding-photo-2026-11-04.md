# FAB@semitoon · 사진모드와 캡쳐타임

상태: 11/4 11:14 KST 사진모드·캡쳐타임·TOP 5 접기 운영 배포 완료. 11:25 KST 후속 상단 버튼/랭킹 여백 축소와 인스타 앱 연결까지 운영 반영·HTTP/계정 보존 검증 완료. 실제 브라우저 및 iPhone 시각/앱 전환 검증은 미실시.

## 승인된 화면 변경

- 왼쪽 위: 인라인 SVG의 폭발하는 장비 아이콘과 `FAB@semitoon`.
- 첫 로딩: `세미툰 | 팹뿌`, `ㄱㄱㄱㄱㄱ`. 기존 시작 단계/오류/재시도 안내와 입장 시간은 유지한다. 에어샤워 첫 문구도 같은 톤으로 표시한다.
- 메뉴 윗부분: 최종 요청으로 `세미툰 팔로우` → 인스타 `semi.toon` 프로필. PC와 수정 키를 이용한 새 탭 열기는 기존 HTTPS 링크를 사용하고, 휴대폰의 일반 탭은 앱 열기를 먼저 시도한다. iPhone은 공식 프로필의 `al:ios:url`, Android는 공식 앱 패키지/프로필 URL과 Chrome intent의 HTTPS fallback을 사용한다. 1.6초 동안 화면을 떠나지 않았을 때 웹으로 연결하되, 앱/다른 페이지로 전환하거나 게임에 다시 입력하면 취소한다. 오래 중단된 타이머도 복귀 후 실행하지 않는다. 자동 팔로우/앱 설치 여부 수집은 하지 않는다.
- 상단 버튼: 효과음 → 공조음 → 카메라 → 메뉴를 한 줄에 배치하고 높이 36px, 버튼 사이 3px로 축소한다. 380px 이하에서는 효과음/공조음의 장식 기호만 숨기고 글씨를 유지한다. 카메라는 처음 배포 시 위치 표시 아래에 있었지만 사용자가 나란히 두도록 수정 요청했다.
- 카메라 사진모드는 메뉴/조이스틱/이모지/랭킹/기록 등 HUD를 숨긴다. 안내는 1.6초 후 사라진다. 화면 한 번 누르기 또는 Esc로 복귀하며, 이 종료 탭이 장비 누르기/이동으로 전달되지 않는다. 화면을 나가면 복귀한다.
- 사진모드에서 서버 연결과 월드 갱신은 계속된다. 게임을 정지하거나 개인 캐릭터에 무적/숨김 권한을 주지 않는다. 조이스틱 입력을 멈추고 HUD의 접근 가능 상태를 복귀 시 원래대로 돌려놓는다.
- 메뉴 `캡쳐타임`: 현재 장면과 기존 닉네임/칭호/누적 파괴·수리를 보여 주는 기록 카드. 위에 `캡쳐타임`, 아래에 게임 주소와 실제 인스타 계정을 표시한다. 사용자 기기의 기본 캡처를 사용한다.
- 파괴 TOP 5 제목 버튼으로 접기/펼치기. 접어도 기존 점수 갱신은 유지하고 다시 펼치면 최신 내용이 나온다. 현재 페이지에서만 접힘 상태를 보관한다. 추가 요청으로 제목의 시각적 최소 높이는 28→20px, 내부 위아래 여백은 5→3px로 줄였으며 제목 글씨 크기는 유지한다. 투명 터치 영역은 높이 24px다.
- 휴식 구역 홍보, 첫 10대 파괴 홍보, 놀이터 문구는 사용자가 반려했다. 추가하지 않았다.

## 저장 및 성능 범위

- 사진 파일 업로드, 촬영 이력, 기록 사본, 사진용 서버 저장소/API를 만들지 않는다. 캡쳐타임 진입/사진모드 사용에 분석 이벤트도 추가하지 않는다.
- 사진모드는 UI만 숨긴다. 캡쳐타임의 1장 미리보기는 이미 그린 WebGL 프레임을 최대 변 1,100px의 2D 캔버스로 읽어 일시적 data URL로 표시한다. 닫으면 이미지 참조를 제거한다. 디스크/브라우저 저장소에도 저장하지 않는다.
- 별도 렌더러, preserveDrawingBuffer, 이미지 변환 서버, 외부 공유 라이브러리를 추가하지 않는다. 카드 코드/CSS는 메뉴를 누른 뒤에만 불러온다. 사진모드는 기존 view-controls 모듈을 재사용하여 필수 네트워크 요청이 늘지 않는다.
- 게임 ID·닉네임·기록·칩·구매품, 기존 운영 분석 집계와 서버 소스/바인딩/마이그레이션은 변경하지 않는다.

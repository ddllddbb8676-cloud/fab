# FAB@semitoon · 사진모드와 캡쳐타임

상태: 구현/로컬 기능 검사 완료, 운영 배포 전. 실제 브라우저 및 iPhone 시각 검증은 미실시.

## 승인된 화면 변경

- 왼쪽 위: 인라인 SVG의 폭발하는 장비 아이콘과 `FAB@semitoon`.
- 첫 로딩: `세미툰 | 팹뿌`, `ㄱㄱㄱㄱㄱ`. 기존 시작 단계/오류/재시도 안내와 입장 시간은 유지한다. 에어샤워 첫 문구도 같은 톤으로 표시한다.
- 메뉴 윗부분: `세미툰 바로가기` → `https://www.instagram.com/semi.toon/`, 새 탭 요청과 noopener/noreferrer를 사용한다. 브라우저/인스타 앱에 따라 열리는 방식은 다를 수 있다.
- 상단 위치 표시 아래 작은 카메라: 사진모드. 메뉴/조이스틱/이모지/랭킹/기록 등 HUD를 숨긴다. 안내는 1.6초 후 사라진다. 화면 한 번 누르기 또는 Esc로 복귀하며, 이 종료 탭이 장비 누르기/이동으로 전달되지 않는다. 화면을 나가면 복귀한다.
- 사진모드에서 서버 연결과 월드 갱신은 계속된다. 게임을 정지하거나 개인 캐릭터에 무적/숨김 권한을 주지 않는다. 조이스틱 입력을 멈추고 HUD의 접근 가능 상태를 복귀 시 원래대로 돌려놓는다.
- 메뉴 `캡쳐타임`: 현재 장면과 기존 닉네임/칭호/누적 파괴·수리를 보여 주는 기록 카드. 위에 `캡쳐타임`, 아래에 게임 주소와 실제 인스타 계정을 표시한다. 사용자 기기의 기본 캡처를 사용한다.
- 파괴 TOP 5 제목 버튼으로 접기/펼치기. 접어도 기존 점수 갱신은 유지하고 다시 펼치면 최신 내용이 나온다. 현재 페이지에서만 접힘 상태를 보관한다.
- 휴식 구역 홍보, 첫 10대 파괴 홍보, 놀이터 문구는 사용자가 반려했다. 추가하지 않았다.

## 저장 및 성능 범위

- 사진 파일 업로드, 촬영 이력, 기록 사본, 사진용 서버 저장소/API를 만들지 않는다. 캡쳐타임 진입/사진모드 사용에 분석 이벤트도 추가하지 않는다.
- 사진모드는 UI만 숨긴다. 캡쳐타임의 1장 미리보기는 이미 그린 WebGL 프레임을 최대 변 1,100px의 2D 캔버스로 읽어 일시적 data URL로 표시한다. 닫으면 이미지 참조를 제거한다. 디스크/브라우저 저장소에도 저장하지 않는다.
- 별도 렌더러, preserveDrawingBuffer, 이미지 변환 서버, 외부 공유 라이브러리를 추가하지 않는다. 카드 코드/CSS는 메뉴를 누른 뒤에만 불러온다. 사진모드는 기존 view-controls 모듈을 재사용하여 필수 네트워크 요청이 늘지 않는다.
- 게임 ID·닉네임·기록·칩·구매품, 기존 운영 분석 집계와 서버 소스/바인딩/마이그레이션은 변경하지 않는다.

## 검사

- 사진모드 진입/종료와 접근 상태 복구, 종료 탭 전파 차단, 안내 제거, Escape/백그라운드 복귀, 시작 중 진입 거부, 기록 카드 표시/닫기, 캡처 실패/중도 닫기, 이미지 크기 제한: 단위 검사 5개 통과.
- 실제 main을 DOM/GPU 모형에서 실행해 360대 초기화·기존 검증 계정 재연결, 사진모드 3회 전환 중 월드 프레임 갱신, TOP 5 접기/펼치기, 기존 99/27 기록 카드와 임시 이미지 폐기, 추가 앱 요청 0회와 칩 보존을 확인했다.
- 기본 전체 테스트 457개 통과, 실패 0개, 기존 최대 수집량 검증 1개는 기본 실행에서 제외. 이번 변경은 그 분석 코드에 영향을 주지 않는다.
- `npm run check`, 신규 모듈 구문 검사, 빌드 확인. 증거: `outputs/brand-photo-release/`.
- in-app Browser는 unavailable이었다. computer-use는 Windows의 현재 브라우저 URL을 신뢰성 있게 확인할 수 없다는 이유로 종료돼 이후 앱 입력을 중단했다. DOM 검사는 실제 브라우저 레이아웃·iPhone 조작 검사가 아니다.

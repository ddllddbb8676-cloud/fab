# 시점 조작 원복

사용자가 원하지 않는 자동 회전으로 멀미를 느껴 카메라를 손대기 전으로 되돌려 달라고 요청했다. 19:23의 상향 회피와 19:44의 측면 회피를 모두 취소한다.

- `src/explorer.js`를 카메라 작업 직전 `b1bd6fd`의 파일과 완전히 같게 복원한다. 기본 거리, 드래그/핀치, 장애물 앞 거리 보정, 조이스틱 방향 계산도 그 기준으로 돌아간다.
- 스토커 IN/OUT을 누를 때 별도로 카메라 각도나 거리를 바꾸던 호출을 제거한다.
- OUT 터치 범위 확대, IN과의 분리, 열린 문이 글씨를 가리지 않는 변경은 유지한다.
- 이벤트 일정/보상, 서버, 계정·칩·구매·기록은 변경하지 않는다. 베이 성공 연출 등 이전부터 있던 명시적 이벤트 카메라는 그대로다.

기존 카메라 동작에 맞는 검사와 OUT 터치/이벤트 검사를 포함한 77개, 구문 검사, 빌드가 통과했다. 원복 기준과 Explorer Git blob 일치를 검증한다. 이번 원복은 실제 iPhone이나 새 브라우저 시각 검수를 수행했다고 주장하지 않는다.

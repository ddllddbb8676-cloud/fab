# 입구 카트 모서리 끼임 수정

사용자가 스토커와 에어샤워 사이에서 카트를 끌다가 빠져나오지 못한다고 신고했다. 기존 계산은 손잡이가 카트에서 멀어질 때만 카트를 이동시켰다. 뒤로 움직이면 캐릭터만 멈춰 있는 카트에 붙어 탈출을 위한 후진이 불가능했다.

카트를 잡고 손잡이 쪽에서 뒤로 움직일 때도 카트가 따라 움직이고, 기존의 점진적인 회전으로 받침대를 피해 방향을 바꿀 수 있게 했다. 클라이언트와 서버가 같은 계산을 사용한다. 큰 지연으로 여러 이동이 한 번에 도착해도 이동 후 카트와 캐릭터 사이의 간격으로 충돌을 판단한다. 전체 카트의 충돌 검사와 순간이동 제한은 유지한다. 카메라·조이스틱과 기본적으로 끌고 다니는 방식은 변경하지 않았다.

## 검증

- 신고 당시 운영에서 읽기만 한 입구 카트 좌표를 격리한 환경에 재현했다. 실제 사용자 위치/아이템을 조작하지 않았다.
- 모서리에서 방향 전환 후 후진하여 통로로 탈출, 벽 통과 거부, 지연된 후진 위치 수신을 검사했다.
- 탑승자, 적재 FOUP의 기존 ID, 지갑, 서버 재시작 후 적재품 복원을 검사했다.
- 관련 25개 검사 통과. 전체 591개 중 590개 통과, 기존 선택 검사 1개 생략. 정적 빌드 완료.
- 격리한 실제 Worker와 Chrome 390×660 화면에서 조이스틱을 직접 드래그해 카트를 모서리에서 꺼냈다. FOUP 4개와 손잡이 연결이 유지되었고 콘솔 오류가 없었다. 시점은 직접 드래그할 때만 변경했다. 실제 iPhone은 검증하지 않았다.
- 같은 Worker에 WebSocket/HTTPS로 각각 접속해 36번의 이동으로 실제 서버 판정상 탈출했다. 양쪽 모두 적재품 4개, 손잡이 연결, 놓기 동작을 확인했다.
- 근거: `outputs/cart-corner-release/tests.log`, `browser-verification.json`, `before.png`, `after.png`.

- 가로 120m × 세로 180m × 층고 5m의 FAB, 장비 360대, OHT와 FOUP, 에어샤워, 방진복 캐릭터.

- 과거 방문자와 0점 기록까지 포함한 닉네임 중복 방지. 기존 중복 이름의 숫자 구분, 공백 포함 7자 이내, 안전팀 별칭 예약.
- 장비 파손 상태의 영구 저장. 서버 재시작 시 장비 전체가 복구되지 않는다.

## 아직 진행하지 않은 작업

- 터치 조이스틱, 이동 속도 상향, 방향 전환 개선, 술래잡기용 넓은 카메라: 의견만 검토한 상태다. 현재 이동 방식과 속도는 유지되어 있다.

## 실행과 데이터 범위

- 의존성 설치: `npm ci`. 정적 로컬 미리보기: `npm start` (기본 주소 http://127.0.0.1:4173).
- 공유 서버를 로컬에서 시험할 때는 `.dev.vars`에 `FAB_ENVIRONMENT=local`을 지정한 뒤 `npx wrangler dev`를 사용한다.
- 배포 대상·바인딩은 `wrangler.jsonc`에 있다. Cloudflare 인증은 작업 환경에서 별도로 수행한다.
- Git에는 소스, 테스트, 배포 설정, 빌드 결과와 할 일을 저장한다. `.env`, `.dev.vars`, 로그인 토큰, 로컬 서버 데이터, `outputs`의 개인 기록·검증 자료는 제외한다.
- 실제 사용자 기록·닉네임 예약의 원본 프로필과 현재 장비 파손 데이터는 운영 중인 Cloudflare 저장소에 있다. 이 Git 저장은 운영 데이터베이스의 복사본이 아니다.
- `server/equipment-bootstrap.json`은 과거 최초 이전용 초기값이며 최신 장비 상태가 아니다. 기존 운영 저장소에 상태가 있으면 그 저장값을 사용한다.

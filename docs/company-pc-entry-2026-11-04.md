# 회사 PC에서 느린 입장 확인

상태: 클라이언트 수정 및 검증 완료, 운영 반영 대기.

회사 PC에서 닉네임 확인 응답이 늦다가 통과했고 에어샤워도 오래 걸린다는 신고다. 사용자는 사내 보안이 막는 경우 우회하지 말고 포기하겠다고 했다. 사내 정책 변경/보안 프로그램 해제/차단 우회를 하지 않는다.

## 관찰과 범위

- 외부 환경의 기존 검증 계정에서 읽기 전용 `nickname-check` 응답은 WebSocket 123ms, HTTPS 133ms였다. 두 경로의 기존 계정 지갑/기록 해시는 일치했다. 닉네임 확정이나 구매/게임 행동은 보내지 않았다. 이 소수 표본은 회사 PC의 통신 품질을 증명하지 않는다.
- 실제 main 코드를 DOM/GPU 모형으로 초당 2프레임 실행하면 13초 후에도 입장 연출 진행률이 약 10.8%였다. 이동용 0.05초 상한을 입장 연출에도 적용했기 때문이다.
- 회사 PC의 GPU/브라우저 정책이나 실제 프레임 수는 직접 확인하지 않았다. 보안 차단 또는 닉네임 지연의 원인을 확정하지 않는다.

## 수정과 검증

- 입장 연출만 표시 중인 화면의 실제 프레임 간격으로 진행한다. 이동/조이스틱/충돌/게임 효과에는 기존 0.05초 상한을 유지한다.
- 닉네임 입력 중과 숨긴 탭에서는 입장 시간이 진행되지 않는다. Esc/건너뛰기와 기존 위치 복원은 유지한다. 서버/통신/사용자 기록/칩/분석 저장은 변경하지 않는다.
- 같은 2fps 모형에서 13초의 표시 중 시간 후 입장을 완료했다. 닉네임 입력/숨긴 탭의 일시정지, 추가 요청 0회, 기존 계정 기록 보존도 확인했다.
- 전체 462개 중 461개 통과, 기존 최대 분석량 검사 1개 기본 제외. 실제 main의 재접속 위치 복원, 27개 이모지/세로 넘김, TOP 5 접힘, 사진모드/기록 카드 검증도 통과했다. 구문/빌드/차이 검사 통과. 실제 회사 PC/iPhone 시각 검증은 미실시다.
- 증거: `outputs/company-pc-entry-release/`의 before/after, server-probe, ui-verification, tests 파일. 준비 운영 버전 `18dfd9cc-38ea-46f9-b64d-bb42258ee7e8`, 소스 `54602d9`.

이번 수정은 느린 환경에서 입장 연출이 불필요하게 늘어지는 문제를 다룬다. 회사 PC의 전체 3D 성능이나 사내망 정책을 해결했다고 보고하지 않는다.

## 적용과 성능

서버와 클라이언트가 같은 collection-catalog.js를 읽는다. 구매·잔액 차감·소유권 검사는 기존 서버 로직을 사용하며 기존 가격과 구매 기록, 인증·이벤트·이동 규칙, DB 구조는 변경하지 않았다.

승인된 3D 모델을 그대로 사용한다. 액세서리는 최초 착용 때 만들고 템플릿을 공유한다. 방진복 6종은 256×512 PNG를 비동기로 읽고 몸체 UV·재질·텍스처를 공유한다. 이미지 응답을 기다리며 게임 입장을 막지 않는다. 실패 시 대표 단색을 표시한다. 40명 동일 방진복 검사에서 의상은 8개 인스턴스 배치로 표시됐다. 원거리 대체 캐릭터는 기존처럼 단색이다. 안전팀 및 흑백 이벤트의 지정 방진복 색이 우선하며 원래 구매·장착 기록을 바꾸지 않는다.

옷장에 실제 모델 썸네일을 사용한다. 프로펠러/UFO 움직임과 늦게 도착한 무늬만 최대 15fps로 다시 그린다. 정적인 시착은 연속 렌더링하지 않으며 옷장을 닫으면 갱신 루프를 해제한다. 이미지 25개는 총 약 397KiB이며 필요한 의상/상점 분류에서만 로드한다.

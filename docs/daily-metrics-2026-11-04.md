# 일별 접속 계정 그래프와 시간별 축

사용자가 어제 접속한 계정 수를 물은 뒤, 운영 현황의 일별 꺾은선 그래프와 시간별 그래프 Y축 표시를 요청했다.

- 일별 접속은 서버에 저장된 `metrics:v1:day:*` 버킷의 고유 계정 수다. 같은 날 재접속한 계정은 한 번만 센다. 시간별 고유 수를 더해서 만들지 않는다.
- 관리자 API에 최근 30일의 `daily` 배열을 추가한다. 날짜는 한국 시간이다. 과거 일간 집계는 이미 저장되어 있으므로 추가 사용자 이력 수집이나 프로필 전체 조회를 하지 않는다.
- 수집을 중간에 시작한 첫날은 `partial`, 오늘은 `ongoing`으로 구분한다. 빠진 날짜는 미수집이며 0으로 채우지 않는다. 집계 상한에 도달한 경우 `limited` 하한 표시도 유지한다.
- 운영자와 사람 안전팀을 포함한 실제 계정 기준이며 NPC와 지정 검증 계정은 제외한다. 기기/브라우저가 다르면 같은 사람도 여러 계정일 수 있다.
- 일별 꺾은선에 날짜·Y축 계정 단위·숫자 표와 어제/오늘 요약을 표시한다. 시간별 막대는 기존의 최고 동시 접속을 유지하고, 정수 Y축 눈금과 누적 계정 수가 아니라는 설명을 붙인다.
- 관리자 인증은 기존 운영자 쿠키만 허용한다. 일반/익명 요청과 기존 게임 기록·지갑·구매품 보존을 검사한다.

어제 합계의 확인은 고정된 11/3 일간 버킷과 수집 시작 메타데이터만 읽는 만료형 비공개 일회성 조회로 수행한다. 원시 계정 지문·ID·닉네임·인증값은 반환하지 않는다. 조회 후 승인된 그래프 영구 버전으로 전환하여 임시 접근 경로를 제거한다. 예상하지 못한 다른 배포를 덮어쓰지 않는다.

검증/배포/부분 집계 결과는 Git 제외 경로 `outputs/daily-metrics-20261104-release/`에 보관한다. 실제 iPhone 시각 검증은 별도로 구분한다.

## 배포 전 검증

- 전체 테스트 398개, 구문 검사와 정적 빌드 통과. 게임 클라이언트 자산은 변경하지 않았다.
- DOM 검사에서 일별 중복 없는 날짜 배열·부분 수집·오늘 진행 중·기록 누락과 실제 0의 구분, 시간별 Y축 눈금과 막대 높이, 기존 닉네임 방문/권한 처리를 확인했다.
- 격리한 Wrangler에서 운영자 페이지/API 200, 익명·일반 API 403, 일별 API와 오늘 합계 일치, 관리자 조회가 추가 참가자를 만들지 않음을 확인했다.
- 일회성 조회 인증/고정 두 키/식별자 미노출 테스트 2개와 로컬 실제 경로 검사를 통과했다. 저장되지 않은 어제는 0이 아니라 미수집으로 반환한다.
- 배포 실행은 독점 파일 잠금, 소스와 운영 버전 재검사, 실패 시 본인이 활성화한 버전만 원복하는 절차를 사용한다. 임시 인증은 10분 후 만료하고, 정상 완료 시 임시 경로 자체를 제거한다.
- 실제 브라우저 및 iPhone 시각 검증은 미실시다.

- 기존 검증 계정의 ID·본래 닉네임·파괴/수리·칩/보유품 해시가 배포 전후 일치한다. 기존 소유자·검증 계정 secret과 방/프로토콜을 변경하지 않았다.
- `completed.json`, `verification.json`, `recovery.json` 모두 완료다. `yesterday.json`은 식별자가 없는 고정 날짜 집계다. 이 실행을 재실행하거나 이전 운영 버전으로 되돌리지 않는다.

## 조작·호환·성능

- 세로 이동 14px 이상에서 손을 놓으면 정확히 한 줄 이동한다. 가로/대각선 드래그, 원점으로 되돌린 드래그, 다중 터치, 취소, 화면 전환 뒤 유령 클릭은 감정표현을 보내지 않는다. 새로 누른 실제 탭은 바로 허용한다.
- 기존 감정표현 버튼과 이벤트 처리기를 그대로 두고 현재 줄 밖의 버튼만 hidden 처리한다. 화면 회전/폭 변경 시 현재 항목을 유지하며, ResizeObserver와 입력 이벤트에서만 계산한다. 프레임별 계산/서버 저장/통계 요청을 추가하지 않는다.
- 기존 공유 서버가 사용하는 카탈로그에 새 8개 ID만 추가했다. 선택 목록에서 뺀 과거 3개 ID도 이미 열린 구버전 클라이언트 호환을 위해 검증/표현은 계속 허용한다. 새 화면에서는 보이지 않는다. 전체 유효 ID 25개, 메뉴 22개, 프로토콜 20과 3초 표현/전송 제한은 유지한다.
- 사용자 ID·이름·칩·구매품·파괴/수리와 운영 분석/DO 마이그레이션은 변경하지 않는다.
- 🫪는 [Unicode 17의 distorted face](https://unicode.org/emoji/charts-17.0/emoji-released.html) 그대로 사용하며 기기 글꼴에 따라 표시 가능 여부/모양이 달라질 수 있다.

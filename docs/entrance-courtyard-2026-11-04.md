# 입구 공간과 뒤쪽 복도 정리 · 2026-11-04

에어샤워 때문에 장비열 뒤에 약 10m 깊이로 남던 빈 복도를 줄이고, 나오자마자 STK01을 볼 수 있게 조정했다.

- 양쪽 외벽 구간 x=±14~60m의 전면을 z=82m로 당겼다. 마지막 장비 끝 z=80.075m와 사이에 1.925m 통로가 남는다. 중앙 28m 폭에는 에어샤워와 STK01·02가 있는 입구 공간만 남는다.
- 에어샤워 앞문은 z=82.2→85.4m, 내부 깊이는 6.6→3.4m다. 뒤벽은 그대로 유지하고 노즐·바닥·천장·충돌 범위도 함께 줄였다. 출구는 z=78.8→81.5m다.
- 처음 입장할 때만 출구에서 STK01 쪽으로 시선을 부드럽게 돌린다. 평소 조이스틱·드래그·추적 카메라 설정은 그대로다. 유효한 저장 위치로 재접속하면 기존 위치를 유지하고 입구 시선을 강제로 적용하지 않는다.
- 새 출구는 초록 휴식 구역 안이다. 출구 좌표는 이전 버전 문과도 겹치지 않아 롤백 후 갇히지 않는다.
- 길찾기는 기존 격자의 끝 통로를 z=81.2m로 옮겼다. 360대 장비, 6대 스토커의 위치·재고·입출고 규칙은 유지한다. 벽 뒤에 있던 저장 사용자 위치는 안전한 입구로 복원하며 기록·칩·구매품은 변경하지 않는다.
- 이전 빈 구간 바닥에 있던 FOUP은 같은 ID와 파손/청소 상태를 유지한 채 벽 앞 통로로 옮겨 복원한다. 새로 던지는 FOUP은 벽에서 튕긴다.
- 서비스 벽은 기존 재질/박스 인스턴스를 재사용한다. 새 모델·텍스처·음원을 요청하지 않는다. 전체 보기에서도 막힌 영역이 다시 빈 바닥으로 나타나지 않는다.

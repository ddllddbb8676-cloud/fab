# 이벤트 시작 안내와 안전팀 NPC 속도

- 베이 뿌시기 예고 카드와 시작 전 공지에 `60초 안에 해당 베이의 장비 20대를 전부 부수세요!`를 표시한다. 진행 중에도 20대 전부 파괴가 성공 조건임을 안내한다. 2개 베이 모드는 전체 60초 동안 베이마다 20대를 전부 파괴하는 방식임을 안내한다.
- 흑백 풉 쟁탈전 모집 화면에 방진복과 같은 색 원에 풉을 모으라고 안내한다. 팀이 정해지면 `흰 방진복 → 흰 원` / `검정 방진복 → 검정 원`을 표시하며 경기 중에도 유지한다. 던져 넣기와 상대 풉 가져오기를 안내한다.
- 환경안전팀 NPC 순찰/추격 기본 속도만 2.1 → 1.68m/s로 20% 낮춘다. NPC별 기존 속도 차이는 같은 비율로 유지된다. 사용자/사용자 안전팀의 걷기 3.2m/s와 다른 NPC 속도는 바뀌지 않는다.
- 게임 규칙, 보상/계정 저장, 카메라와 조이스틱은 그대로다.

관련 검사 55개와 실제 UI 함수의 DOM 모형에서 모집/예고 문구, 두 팀별 안내, NPC/유저 속도 구분 검사를 통과했다. 실제 iPhone 화면 검수는 하지 않았다.

배포 여부는 `outputs/event-guide-safety-release/{completed,verification,recovery}.json`을 기준으로 한다. 완료된 실행기는 다시 실행하지 않는다.

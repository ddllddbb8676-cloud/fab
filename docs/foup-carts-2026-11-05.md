# FOUP 카트 2대와 NPC 회수

## 범위와 동작

- 입구 양쪽 스토커 앞에 CART01/02를 한 대씩 배치한다. 길이 1.70 m의 2단 카트이며 각 단 앞뒤로 FOUP 두 개, 총 네 개를 싣는다.
- 각 단에는 이용자가 한 명씩 앉을 수 있다. 탑승하는 단의 FOUP 두 개만 주변 바닥으로 떨어지고 깨지지 않는다. 탑승으로 칩이 생기지 않는다.
- 가까이 가거나 카트를 누르면 작은 메뉴가 열린다. FOUP 싣기/꺼내기, 위아래 탑승, 손잡이 잡기를 지원한다. 잡은 뒤 카트 뒤에서 양손으로 앞의 손잡이를 잡고 기존 조이스틱으로 민다. 놓기/내리기로 끝낸다.
- 서버가 손잡이 소유자, 단별 탑승자, 칸별 기존 FOUP ID를 검증한다. WebSocket/HTTP 이용자가 같은 카트를 본다. 벽/장비를 통과하는 이동과 오래된 FOUP 요청을 거부한다.
- 홈에서 15 m 넘게 떨어져 120초 동안 이용하지 않은 카트를 기존 상주 NPC 한 명이 회수한다. 새 NPC는 만들지 않는다. 한 번에 카트 한 대만 회수하며 2초 간격으로 후보를 확인한다.
- 손잡이를 잡은 사람/탑승자가 있거나 지상 이용자가 5 m 안에 있으면 회수하지 않는다. NPC가 걸어가는 중 사람이 돌아와도 취소한다. 황금 FOUP이 실린 카트와 흑백 FOUP 이벤트 중에는 회수하지 않는다.
- NPC가 손잡이까지 걷고, 넓은 통로를 따라 뒤에서 밀고 돌아와, 한 개씩 들어 입구 스토커 IN에 올린다. 손을 들어 올리는 동작과 기존 3초 스토커 입고 동작을 사용한다. 정리 후 원래 NPC 행동으로 돌아간다.
- 스토커가 가득 차거나 경로가 막히면 남은 FOUP은 카트/안전한 바닥에 그대로 둔다. 정리 보상이나 기록 변경은 없다.
- 안전팀에게 잡히면 약 1.15초 동안 양손을 들며 움찔하고 `들켰다!`를 띄운다. 안전팀도 손을 뻗는다. 기존 3대 수리 패널티는 유지한다.

## 보존 및 저장

`src/explorer.js`는 기존 카메라 복원 버전 그대로다. blob `470c282e4b6bd07219ca17f7fc801edfa08ca8ce`. 카메라 자동 회전/새 조이스틱 규칙을 추가하지 않는다.

계정 ID·이름·지갑·구매·파괴/수리 기록의 스키마와 보상 규칙은 바꾸지 않는다. 카트 이동 위치는 변경 시 최대 5초 간격으로 기존 FOUP 체크포인트에 저장한다. 체크포인트 v1에 선택적인 `carts` 메타데이터만 추가하며, 구버전은 같은 FOUP을 안전한 바닥 상태로 읽는다. 재시작 시 손잡이/탑승자/NPC 작업은 해제하고 위치와 적재물 ID는 유지한다. 이전 한 대짜리 검수 체크포인트도 읽는다.

실제 제품 형태 참고: [Palbam Class FOUP/FOSB Transport Cart](https://www.palbamclass.com/product/FOUP-FOSB-Transport-Cart). 스테인리스 관 프레임, 2단 선반과 캐스터의 구성을 참고한 자체 Three.js 메시다. 외부 모델·사진·추가 실행 의존성은 배포하지 않는다.

## 11/5 밀기 자세 수정

사용자 사진에서 몸은 카트 반대쪽을 향하고 손은 뒤로 뻗는 자세를 확인해, 카트를 향해 양손으로 앞으로 미는 동작으로 수정했다. 이동할 때 카트는 사람 앞에 있고, 후진 입력은 카트를 갑자기 돌리지 않고 뒤로 이동한다. 옆 방향 입력은 이동 거리에 맞춰 조금씩 조향한다. NPC도 같은 방향을 바라보며 밀고, 복귀 후 선반 옆에서 FOUP을 꺼낸다.

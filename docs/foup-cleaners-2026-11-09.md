## 적용

- 기존 30명 중 한가한 breaker NPC 최대 두 명을 청소에 임시 배정한다. NPC 수, 원래 역할·닉네임·파괴/수리 기록은 유지한다. 다른 작업, 카트 회수, 탑승, 잡힘, 헤롱 중인 NPC는 배정하지 않는다.
- 서버가 60초 이상 관찰한 잔해만 직접 걸어가 약 3.2초간 빗자루로 치운다. 재시작 후 남은 잔해도 60초를 관찰한다. 잔해 ID와 파손 세대는 유지하며 새 객체를 늘리지 않는다.
- 유저가 청소 중이거나 3m 안에 있는 잔해, 황금 이벤트 풉은 제외한다. 유저의 유효한 청소 요청이 오면 NPC가 즉시 양보하며, 유저의 기존 청소 2칩은 단 한 번 지급한다. NPC 청소에는 칩/점수를 지급하지 않는다.
- 베이 이벤트/흑백 쟁탈전과 베이 성공 연출 중에는 청소를 중단하고 잠금을 해제한다. 이벤트가 끝나면 다시 작업한다. 청소 중인 NPC는 안전팀 잡힘이나 풉 피격으로 작업을 잃지 않는다.
- 청소 완료 후 기존 12초 대기 뒤, 작동 중인 로드포트 대비 재고가 가장 적은 베이부터 같은 풉을 돌려놓는다. 동률이면 원래 베이를 우선하고 장비별 쏠림도 줄인다. 고장 난 장비, 이미 찬 포트, 기존 OHT 전용 포트는 보충 대상으로 선택하지 않는다.
- 청소 대상 탐색은 2초 간격이며, 전체 청소조에서 한 번에 경로 탐색 하나만 수행한다. 새 타이머·DB·계정 필드를 추가하지 않고 기존 서버 틱과 FOUP 체크포인트를 쓴다. 5초간 이동이 막히거나 유저가 다가오면 양보하고 다른 잔해를 찾는다.

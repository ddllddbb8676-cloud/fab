# FOUP 파손과 파티클 청소

사용자 확정: 던지기 1칩, **청소 완료 2칩**. 처음 제안한 청소 1칩은 이후 정정됐다.

- 던진 FOUP은 바닥에 충돌하면 케이스가 갈라지고, 웨이퍼 8장이 시간차로 쏟아져 조각으로 부서진다. 파손음과 여러 번의 작은 파편 소리를 함께 재생한다.
- 깨진 잔해는 시간으로 지워지지 않는다. 다른 방문자에게도 같은 위치와 파손 상태로 보인다.
- 잔해를 누르면 앞으로 걸어가 약 3.2초간 큰 빗자루를 양손으로 잡고 좌우로 쓴다. 부드러운 파티클 구름이 옆으로 퍼지며 사라지고, 완료한 사람에게만 2칩이 지급된다.
- 청소 중 이동, 자세 변경, 화면 숨김, 연결 종료 시 중단된다. 잔해는 남고 칩을 주지 않는다. 서버가 거리, 동일 파손 회차, 독점 청소자, 경과 시간을 검증한다.
- 같은 잔해에 대한 중복 클릭·재접속으로 칩을 더 받을 수 없다. 개인 파괴/수리 횟수와 랭킹에는 청소를 더하지 않는다.
- `내려놓기`, 접속 종료에 따른 내려놓기, OHT에서 떨어진 화물은 기존처럼 온전하게 유지된다. 던지기만 파손된다.
- 청소를 끝낸 잔해는 제거되고, 약 12초 뒤 사용 가능한 빈 로드포트에 새 FOUP을 보충한다. 막힌/고장 난/이미 찬 포트에는 보충하지 않는다. 같은 화물 슬롯을 재사용하며 무한히 새 객체를 만들지 않는다.
- NPC도 던지면 깨진다. 자기 잔해가 치워지기 전에는 추가로 던지거나 잔해를 자동 제거하지 않는다.

## 저장과 화면

기존 방 `FAB-A-v20`, 프로토콜 20, 사용자 식별 쿠키와 프로필/장비 저장 키를 유지한다. `world:foups:v1`에 이동한 화물과 파손·제거 상태를 추가 저장하며, 청소 결과와 개인 칩은 같은 저장 배치로 확정한다. 기존 저장이 없는 경우에만 초기 FOUP 배치를 만든다. 서버 재시작 중 중단된 던지기는 파손 결과로 복원하며, 중단된 청소는 잠금을 풀고 잔해를 유지한다.

FOUP 패킷은 기존 열 다음에 파손 회차·경과 시간·청소자·진행률·방향을 추가한다. 늦게 접속한 화면에서는 이미 깨진 잔해를 정착 상태로 표시하고 충돌음/붕괴를 다시 재생하지 않는다. 변경 전 화면을 오래 켜 둔 이용자는 새로고침해야 새 연출이 보인다.

기존 카메라/조이스틱 설정을 유지한다. 새 상시 버튼은 없고 잔해 터치로 청소한다. 청소 중에도 조이스틱으로 중단할 수 있다. 효과음 끄기와 감소된 동작 설정을 따른다. 먼 잔해는 단순화하고, 가까운 최대 64개 묶음만 자세히 그린다. 정착한 잔해의 인스턴스 행렬은 재사용한다.

## 검증

- 전체 테스트 258개 통과: 기존 조이스틱/OHT/꾸미기/기록 보존 포함.
- 추가 테스트: 던지기/내려놓기 구분, 잔해 유지, 동시 청소, 2칩 단회 지급, 취소/퇴장, 중복/오래된 조작, 저장/재시작, 모델/파편/먼지 유한값, 빗자루 바닥 접촉.
- 로컬 Cloudflare Worker에서 실제 WebSocket 두 세션으로 파손 공유→동시 청소 거절→퇴장 취소→재접속→완료 2칩을 검증했다. Worker 프로세스 재시작 후 잔해·제거 상태·양쪽 칩을 다시 확인했다.
- 실제 Three.js 모델의 파손/정착/청소 장면을 Blender로 렌더링해 형상을 확인했다. 브라우저 사용 설정이 꺼져 있어 실제 모바일 브라우저/GPU 동작 검증은 수행하지 못했다.
- 개인 데이터/점검 쿠키/렌더 원본은 Git에서 제외되는 `outputs/`에만 둔다. 카카오·구글 로그인은 보류 상태를 유지한다.

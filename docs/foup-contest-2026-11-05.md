# 흑백 풉 쟁탈전

운영자가 게임 메뉴의 **운영 현황 → 이벤트 시작 → 흑백 풉 쟁탈전 모집**을 누르면 30초 동안 참가자를 모집한다. 실제 경기는 3분이다. 베이·황금 이벤트가 진행 중이거나 다음 정기 황금 시간까지 모집과 경기를 마칠 수 없으면 시작 버튼이 잠긴다.

- 게임의 **참여하기**를 누른 사람은 중앙통로 가운데로 모인다. 일반 참가자는 신청 순서대로 백·흑 팀을 번갈아 맡는다. 모집 종료 시 접속해 있는 인원이 홀수면 게임에 들어와 있는 운영자가 흑팀에 합류하고, 짝수면 파란 방진복으로 관전한다. 참가자가 없거나 홀수에 운영자가 게임에 없으면 모집을 마치고 이유를 안내한다.
- 중앙통로 베이 앞에 흑·백 원 세 쌍을 표시한다. 참가자가 던진 풉은 바닥에서 튀고 온전하게 멈춘다. 한 풉을 상대 원에서 집으면 그 팀의 점수가 빠지고 다른 원에 안착하면 해당 원의 팀이 한 점을 얻는다. 접수한 실제 참가자가 다룬 풉만 각 경기의 대상으로 삼는다. 일반 던지기 1칩과 종료 보상은 별도로 계산한다.
- 종료 시 자기 팀 세 원의 풉 수에 승 30, 패 15, 무승부 20을 곱해 참가자 각각에게 지급한다. 진행 중 퇴장한 팀원도 지급 대상으로 유지한다. 방 상태와 지갑은 기존 저장 경로에서 확정하고, 운영자 시작 요청을 재전송해도 같은 경기가 한 번만 열린다.
- 방진복 색만 백·흑·파랑으로 표시한다. 본인과 다른 사람에게 머리·안경·가방·눈이 원래대로 보이고, 경기 중 바꾼 장식도 즉시 반영한다. 상점 보유품과 실제 장착 슬롯은 그대로이므로 종료 후 개인 방진복이 다시 보인다.

## 검증

격리 Worker에서 운영자·일반 두 팀의 WebSocket으로 실제 모집·참가·중앙 집결·짝수 관전·던지기·상대 원에서 빼앗기·종료 보상·복장 복원·재접속을 확인했다. 회귀 검사에는 홀수 운영자 합류, 동점·패배 보상, 저장 복원, 퇴장한 팀원 지급, 경기 후 일반 파손도 포함한다. 전체 검사 545개 중 544개 통과, 기존 선택 검사 1개 생략.

390×844 브라우저 검수에서 관리자 모집 버튼, 게임 참가 안내와 점수판, 고양이 귀·하트 안경·거북이 가방을 착용한 캐릭터의 팀 색과 종료 후 원래 방진복을 확인했다. 실제 휴대폰 검증은 별도다. 근거는 `outputs/foup-contest-release/`에 둔다.

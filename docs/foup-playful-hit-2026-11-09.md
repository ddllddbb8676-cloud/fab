# 걷거나 서 있는 캐릭터끼리 FOUP 맞히기 — 2026-11-09

11/9 14:07 KST 운영 반영 및 배포 후 검증 완료. 안전팀에게만 적용하던 FOUP 피격을 일반 유저와 일반 NPC까지 확대했다. 사용자의 추가 조건대로 평소 걷거나 서 있는 상태에서만 적용한다.

## 동작

- 날아오는 FOUP에 몸이 닿거나 깨지는 바닥의 1.65m 안에 있으면 😡를 표시하고 2초간 헤롱거린다. 비행 구간 전체를 검사하는 직접 명중 반경 0.62m는 유지한다.
- 평소 지상 이동과 서 있기만 대상이다. 수리, 장비 조작과 작업하러 접근, 청소, OHT 승하차/탑승, 카트 끌기/탑승/회수, 앉기/눕기, 잡히거나 잡는 모션, 숨겨진 입장 상태, 초록 휴식 구역은 제외한다. 작업 중인 사람은 풉을 가로막지도 않는다.
- 자기 풉에는 직접 명중과 바닥 범위 모두 영향을 받지 않는다. 10초 재기절 방지로 연속 피격이 2초 정지를 늘리지 않는다. 헤롱 중에는 안전팀의 잡힘이 중복되지 않는다.
- 걷거나 선 채 들고 있던 풉은 같은 ID로 유지한다. 회복 후 다시 던질 수 있다. 일반 NPC는 원래 보행 경로를 보존하고 회복 후 이어 걷는다. 헤롱 중 새 작업/카트 회수 담당으로 전환되지 않는다.
- 흑백 쟁탈전의 깨지지 않는 투척, 떨어뜨리기, 잔해 복원은 피격을 발생시키지 않는다. NPC의 가끔 안전팀에 던지는 시범과 이벤트 중 시범 중지 규칙은 유지한다.
- 별도 칩 보상이나 패널티를 추가하지 않는다. 기존 투척/청소 보상, 프로필·지갑·보유품, FOUP ID/저장 형식과 프로토콜 20을 유지한다. 카메라 자동 회전도 추가하지 않는다.

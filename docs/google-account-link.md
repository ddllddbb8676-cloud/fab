## 공개 설정

1. 팹뿌용 Google Auth Platform에서 외부 이용자용 브랜딩과 지원 메일을 설정한다. 홈페이지는 `https://fab.semitoon.com`, 구글 연결 개인정보 안내는 `https://fab.semitoon.com/account/privacy`이다. 운영 공개 시 대상 및 Google이 요구하는 도메인 확인 사항을 점검한다.
2. 웹 애플리케이션 클라이언트의 승인된 JavaScript 원본에 `https://fab.semitoon.com`을 등록한다. 버튼의 JavaScript 콜백을 사용한다. 공개 클라이언트 ID만 Worker 변수로 지정한다. 클라이언트 보안 비밀번호와 사용자 인증 토큰을 저장소나 로그에 넣지 않는다.
3. 다음에 설정을 바꿀 때도 기존 Durable Object와 운영자·통계 제외 바인딩을 보존한다. 등록을 해제해 일시적으로 닫을 때는 변수가 비어 있으면 메뉴가 숨겨지고 상태 API가 `{"enabled":false}`를 반환한다.

## 이용 흐름

- 처음 온 기기에서 ‘구글로 시작하기’를 누르면 같은 구글에 연결한 캐릭터는 바로 열린다. 처음 사용하는 구글이면 해당 브라우저의 새 FAB ID에 연결한 뒤 게임의 첫 입장에서 닉네임을 정한다. ‘구글 없이 바로 시작’은 기존 게스트 게임으로 이어진다. 첫 화면을 보는 것만으로는 방에 접속하지 않는다.
- 기존 이용자는 원래 닉네임이 보이는 게임에서 메뉴 → 내 캐릭터 · 구글 연동 → 이 캐릭터 구글에 연결을 누른다. 이름을 확인해 확정하면 다른 기기의 첫 화면이나 닉네임 창에서 같은 구글 계정으로 로그인할 수 있다.
- 실수로 다른 캐릭터를 연결했다면 원래 캐릭터가 보이는 기기에서 ‘캐릭터 코드 받기’ → ‘이 캐릭터의 코드 발급’ → ‘캐릭터 코드 복사’를 누른다. 사용할 기기에서 ‘원래 캐릭터 가져오기’에 붙이고 구글 인증 후 두 닉네임을 확인해 확정한다. 구글 연결 대상을 원래 캐릭터로 바꾸고 기존에 발급한 잘못된 캐릭터의 복구 세션을 종료한다. 두 캐릭터의 지갑과 보유품을 별개로 보존한다. 이미 다른 구글에 연결한 원본은 그 구글로 로그인하거나 본인 인증으로 먼저 연결을 해제한다.
- `FAB-`로 시작하는 캐릭터 코드는 플레이 중인 원본 게스트 세션에서만 발급한다. 구글용 인증 코드와 용도와 형식이 다르다. 둘 다 5분 안에 한 번 사용한다. 인스타 등 내장 브라우저의 구글 인증은 Safari/Chrome에서 `/account#code`를 열고 받은 **구글 인증 코드**를 인스타에 붙여 진행한다.
- 구글 인증은 서명, 발급자, 대상 앱, 유효 시간, 일회용 nonce를 서버에서 확인한다. 영구 연결에 쓰이는 구글 식별자는 `sub`의 해시다. 원래 세션 쿠키와 프로필은 유지하고 복구한 기기에만 별도 HttpOnly 쿠키를 발급한다. 이 쿠키는 원래 기기의 세션에도 묶이고 30일 뒤 만료된다.
- 구글 계정과 캐릭터는 각각 하나씩만 연결된다. 다른 브라우저에서 가져온 코드는 5분 안에 한 번 사용하며, 미리보기한 기기가 최종 확인한다. 가린 이메일 표시는 코드와 함께 만료된다. 데이터베이스에서 만료된 임시 자료는 다음 인증 시작 때 정리한다. 프로필을 복사하거나 지갑·아이템을 재지급하지 않는다.
- 기기의 원래 캐릭터로 돌아갈 수 있다. 같은 구글 계정으로 재인증해 연결을 해제하면 다른 기기의 복구 세션도 해제된다. 연결된 프로필의 게임 초기화는 해제 후 진행한다.

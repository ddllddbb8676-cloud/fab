# 조이스틱 이동 적용 — 2026-11-02

## 변경

- 기본 이동: nipplejs 1.0.4의 동적 터치 조이스틱. 왼쪽 아래 144px 영역에서 시작하며 조작 원은 96px이다. 배포 파일에 라이브러리를 함께 포함해 외부 CDN에 의존하지 않는다.
- 손을 떼거나 터치 취소, 창 전환, 메뉴·도움말 열기 시 이동 정지. 이동 손가락과 시점 손가락을 분리하고 시점 터치가 장비 선택으로 이어지는 것을 차단한다.
- 메뉴의 이동 방식에서 기존 바닥 터치로 전환 가능. 이 선택은 해당 브라우저에 저장된다. EMO·FOUP·OHT·파손 장비 선택은 조이스틱 방식에서도 유지된다.
- 사람 이동 속도 2.6 → 3.2m/s. 직접 조작의 가속과 몸 방향 전환을 빠르게 하되 카메라 방향은 유지한다. NPC 일반 1.7, 수리 2.0, 안전팀 2.1m/s로 조정했다.
- 기본 카메라 거리 4.4 → 5.8m, 고도각 .36 → .56rad, 수직 화각 64 → 72도. 장애물 회피와 천장 높이 제한을 유지하고 장애물이 사라질 때 카메라가 완만하게 멀어진다.
- 좁은 통로와 초록 보호 구역 경계를 따라 미끄러지듯 이동하고 닫힌 문을 건너뛰지 않는다.

## 검증

- 전체 Node 테스트 203개 통과, 구문 검사·정적 빌드·Wrangler 배포 사전 검사 통과.
- 실제 브라우저 조이스틱 드래그 이동과 정지 확인. 390×844 모바일 화면 확인.
- 로컬 브라우저에 실제 nipplejs를 로드해 합성 두 손가락 입력으로 이동+시점, 손가락별 해제, 취소, 메뉴 잠금, 바닥 터치 전환 등 11개 검사 통과.
- 합성 입력은 실제 iPhone/Android 터치 기기 검증을 대체하지 않는다. iframe 검증 화면에서는 앱 코드에 없는 MutationObserver 오류가 1건 포착되었지만 단독 FAB 페이지의 오류 로그는 비어 있었다.
- 운영 12개 파일의 SHA-256 일치, WebSocket 프레임 수신, 재접속 ID·닉네임 유지 확인. 점수 보유 방문자 834명 및 당시 최고 기록 1138 유지. 파손 장비 21대 중 18대가 배포 후에도 유지되었고 전체 파손은 20대로, 운영 중 개별 수리·파괴가 계속 진행됐다.

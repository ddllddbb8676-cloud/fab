# 파괴 TOP 5 접힘 유지

상태: 구현/로컬 검증 완료, 운영 반영 대기.

사용자가 접은 TOP 5가 다시 펴진다고 신고했다. 새 페이지로 접속할 때는 펼치되 같은 페이지에서는 직접 다시 펼치기 전까지 선택을 유지한다. 새로고침을 넘겨 저장하지 않는다.

- 접힘 상태를 점수 데이터와 분리하고 목록/빈 상태의 `hidden` 속성, 제목의 접근성 상태를 함께 맞춘다. 갱신할 때 값이 다를 경우에만 DOM을 수정한다.
- 같은 화면에 다시 연결해도 선택과 기존 처리기를 재사용한다. 점수/이름/명단 갱신, 서버 재연결, 사진모드 복귀가 접힘 상태를 초기화하지 않는다.
- 제목에서 드래그하거나 터치가 취소되면 뒤따르는 클릭으로 열리지 않게 한다. 이후 새 탭과 키보드 조작은 정상 처리한다.
- 추가 네트워크 요청/서버 저장/분석 이벤트가 없다. 게임 서버, 분석 서버, 기존 프로필/칩/기록 및 감정표현 카탈로그를 변경하지 않는다.
- 사용자 기기에서 자동 펼침의 정확한 원인을 재현한 것은 아니다. 상태 유지와 오작동 방어를 검증한 수정이다.

검증: 전체 462개 중 461개 통과, 기존 최대 분석량 검사 1개 기본 제외, 실패 0개. 새 회귀 검사 4개와 실제 main DOM/GPU 모형에서 점수 프레임 반복 후 접힘 유지, 수동 펼침, 사진모드 복귀, 추가 요청 0회, 기존 기록 보존을 확인했다. 구문/빌드/차이 검사 통과. 실제 iPhone 시각/터치 검증은 미실시다.

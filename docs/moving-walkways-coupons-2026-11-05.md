# 중앙통로 무빙워크·안전팀 해제 쿠폰·이벤트 NPC 차단

## 적용 내용

- 중앙 통로에 반대 방향의 직선 무빙워크 두 줄을 둔다. 손잡이와 충돌 벽 없이 옆으로 언제든 나갈 수 있다. 서 있거나 같은 방향으로 걸을 때 평소 걷기의 2배(6.4m/s)로 이동한다. 바닥·전체보기·팹 지도에 방향 화살표가 보인다.
- 원래 카트 끌기 방식과 탑승 중 둘러보기를 유지한다. 무빙워크에서 FOUP 네 개 또는 위아래 탑승자가 함께 이동한다. 느린 HTTP 위치 전송에서도 같은 벨트의 정상 이동을 순간 이동으로 오인하지 않도록 서버가 경과 시간과 방향을 확인한다.
- 사용자가 고른 시점과 카메라 입력 코드는 기존 원복 기준 b1bd6fd와 동일하다. Explorer에 보행 후 지면 이동을 반영하는 콜백만 추가했다. 조작 잠금·시착·사진모드·포획/수리·이벤트 시점에서는 벨트가 사용자를 밀지 않는다. 흑백 FOUP 이벤트 모집/진행 중에는 중앙 집결과 득점을 방해하지 않게 벨트를 일시 정지한다.
- 상점에 안전팀 패널티 해제 쿠폰을 30칩으로 추가했다. 여러 장 구매·보관 가능하며 패널티 안내에서 남은 장수와 사용 버튼을 표시한다. 실제 패널티가 있을 때 서버가 한 장을 소비하고 해제하며 12초 재포획 유예를 준다. 구매/사용 버전 검사로 재전송 중복 차감과 임의 가격을 막는다.
- 쿠폰 필드는 거래가 있을 때만 지갑에 추가한다. 기존 계정·지갑을 일괄 변경하거나 칩을 소급 지급하지 않는다. 재접속 시 장수와 구매/사용 횟수가 유지되고 성장 분석에는 실제 쿠폰 칩 소비와 구매를 포함한다.
- 입장 문구는 `세미툰 | 팹뿌` / `하고싶었던거 다하자 ㄱㄱㄱ!!`이다.
- 베이 뿌시기 예고/진행/성공 화면 동안 일반·수리·안전팀·휴식·OHT NPC 모두 해당 베이에 접근하지 않는다. 기존 내부 NPC와 수리 작업을 정리하고 경로 계산·매 이동 구간에서도 진입을 막는다. NPC 카트 회수도 그동안 멈춘다. 2개 베이 모드 전환과 재시작 복원에도 적용한다.

## 검증

- 전체 검사 585개 중 584개 통과, 기존 대용량 옵션 검사 1개 생략. 최종 관련 검사 34개 통과, 동일 옵션 1개 생략. 구문 검사와 빌드 완료.
- 이동 프레임별 속도, 옆으로 이탈, 양 끝, 탭 경로, 카메라 입력 보존, 카트 FOUP/탑승자 동반 이동, 느린 위치 전송과 과도한 이동 차단을 검사했다.
- 모든 NPC 역할을 이벤트 베이 내부에 강제로 둔 격리 검사에서 퇴거·재진입 차단·수리 미발생과 다음 베이·성공 화면·재시작 복원을 확인했다.
- 격리한 실제 Worker의 WebSocket/HTTP 양쪽에서 쿠폰 구매·사용·중복 요청 거부·재접속 보존과 카트 탑승자 이동을 확인했다.
- Chrome 390×844에서 상점 120→90칩/보유 1장, 패널티 1장 사용 후 해제, 새로고침 지갑 보존, 무빙워크 바닥·전체보기 화살표와 사진모드 숨김을 확인했다. 실제 iPhone 검수는 하지 않았다.

배포 자료는 `outputs/walkway-coupon-release/`에 있다. 완료 여부는 `completed.json`, `verification.json`, `recovery.json`으로 판단한다. 완료 실행기를 다시 돌리지 않는다.

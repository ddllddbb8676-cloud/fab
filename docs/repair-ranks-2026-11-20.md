# 수리 직급과 상위 파괴 칭호

2026-11-20 사용자가 마지막 제안 표대로 적용을 요청했다. 기존 누적 수리 횟수로 자동 결정하며 별도 직급 저장이나 기록 이관, 소급 보상은 없다.

회장은 서버에서 인증한 기존 세미 운영자 계정만 표시한다. 닉네임, 클라이언트 제출값, 저장된 임의 플래그로 부여하지 않는다. NPC에는 수리 직급을 붙이지 않는다.

파괴 칭호는 기존 9개를 보존하고 5,000대 FAB 멸망신 / 10,000대 양산의 종말 / 15,000대 실리콘 문명 파괴자 / 20,000대 반도체 아포칼립스를 추가했다. 기존 수동 선택·자동 표시·숨김과 운영자 칭호를 유지한다.

본인·주변 사용자·옷장 미리보기의 이름표는 위에 칭호, 아래에 작은 직급 배지와 닉네임을 표시한다. 칭호 숨김 시 직급과 닉네임은 남는다. 기존 닉네임 글자 크기와 머리 장식 여백, 주변 10명·18m 제한을 유지한다. 이름이나 실제 프로필에는 직급을 접두어로 저장하지 않는다. 수리 횟수가 승진 기준을 넘을 때 짧은 알림을 표시하며 첫 접속 때 기존 기록으로 배정된 직급에는 승진 알림을 반복하지 않는다.

상점·옷장 → 직급 · 칭호에서 현재 직급, 누적 수리, 다음 직급까지 남은 대수와 전체 기준을 볼 수 있다. 방 이름·프로토콜·저장 키·DO 마이그레이션·Google 인증·지갑 규칙은 변경하지 않았다.

## 검증

- 전체 Node 검사: 703개 통과, 1개 선택 검사 생략. 최초 병렬 실행에서 기존 entry 테스트 프로세스가 원인 설명 없이 실패했으나 해당 파일 단독 4개 통과, 동시성 2로 전체 재실행 통과. 게임 코드를 변경해 검사를 회피하지 않았다.
- 구문 검사와 정적 빌드 통과. 단계 경계, 499→500 정상 수리 승진, 중복 완료 거절, 기본 수리 보상 3칩 유지, 운영자 사칭 거절, 주변 캐릭터 재사용 시 직급 잔류 방지 검증.
- 격리 실제 Worker WS·HTTP: 기존 수리 500/20,000대와 운영자 직급, 상위 칭호 선택/숨김, 재접속, 합성 계정 이름·기록·지갑·Google 연결 보존, 관리자 권한 확인.
- 실제 Three.js 캐릭터와 이름표·선택 UI를 내장 브라우저의 데스크톱 및 390px 폭으로 확인. 긴 칭호/닉네임, 머리 장식, 칭호 숨김 후 직급 유지 확인. 실제 iPhone의 GPU·터치 체감 검증은 별도다.

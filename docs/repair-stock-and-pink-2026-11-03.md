# 2026-11-03 수리 장비 보충과 베이비 핑크 방진복

사용자는 수리할 장비를 최소 50대 정도 유지하고, 부족해지면 NPC들이 여러 베이에 골고루 부수도록 요청했다. 이어 협력사 방진복을 베이비 핑크색으로 다시 넣어 달라고 요청했다.

## NPC 수리 장비 보충

- 이전에는 파손 장비 18대 이상이면 파괴 NPC가 쉬었다. 이를 **50대 보존 / 60대 확보 목표**로 변경했다. NPC 13명과 기존 걷기·EMO 누르기·붕괴를 그대로 사용하며 즉시 파손 상태를 만들어 넣지 않는다.
- 파괴 NPC는 파손 수가 적은 베이를 우선한다. 다른 NPC가 이미 향하는 장비도 함께 세어 한 베이에 몰리지 않고, 총 60대 목표를 넘겨 파괴 작업을 과도하게 예약하지 않는다.
- 재고가 부족하면 순찰을 일찍 끝내 작업을 찾고, 다음 파괴까지 쉬는 시간을 1~2초로 줄인다. 플레이어 이동 속도와 조작은 바꾸지 않았다.
- NPC 수리 작업은 예약 중인 수리까지 고려해 50대를 남긴다. 여러 NPC가 함께 수리를 끝내도 50대 아래로 줄이지 않는다.
- **플레이어 수리와 보상은 제한하지 않는다.** 여러 플레이어가 빠르게 수리하면 잠시 50대 미만일 수 있으며 NPC가 실제 이동·파괴로 보충한다. 부족한 상태에서 배포 직후 즉시 50대가 되는 방식도 아니다.
- 플레이어가 사용/수리/OHT 탑승을 예약한 장비는 기존 보호 규칙을 따른다. 방금 수리한 장비는 NPC가 45초간 파괴 대상으로 선택하지 않는다.
- 기존 서버 파손 저장과 NPC 실제 행동 집계를 따른다. 사용자의 파괴 횟수나 칩을 대신 올려 주지 않는다. 방·프로토콜·NPC 수·보상 값은 유지한다.

## 베이비 핑크 복원

- `suit-pink`, **협력사 방진복 50칩**, 베이비 핑크 `#f6d1dc`.
- 이전과 같은 ID로 복원해 이미 산 이용자는 재구매/재차감 없이 보유·착용을 이어간다. 새 지갑이나 프로필을 만들지 않는다.
- 본인/다른 사람/상점은 기존 공통 색상 함수를 사용한다. 아이콘도 같은 색이며 가격 오름차순 정렬을 따른다.
- 기존 방진복 메시의 색상만 변경한다. 새로운 모델·텍스처 다운로드나 렌더러는 추가하지 않았다. 마스크와 얼굴, 안전팀 색상 우선 표시도 유지한다.
- 앞서 배포한 HTTPS 진입, 연결 병행, 무응답 연결 재시도는 유지한다. 과거 분홍색 값이 접속 문제의 원인으로 확인된 것은 아니다.

- 전체 Node 테스트 **317개 통과**. 신규 11개는 베이 분산/예약 상한/수리 하한/동시 완료/사용자 수리 3칩/45초 보호/사용자 우선권/실제 이동 보충, 분홍 신규 구매/기존 소유 복구/재질 분리·안전팀 복귀를 검사한다.
- 실제 방 엔진 300초 모의 실행: 파손 18대 시작 → 85.3초에 50대 도달 → 이후 50~60대 유지. 마지막 59대, 18개 베이에 2~4대씩 분산됐다. 사람이 동시에 수리하는 실시간 운영의 보충 시간과 동일하다는 뜻은 아니다.

- 10:36 KST 운영 확인: 기존 검증 계정으로 실시간 프레임 423개를 관찰했다. 파손 장비 31대에서 55초 뒤 50대, 최종 56대로 늘었으며 18개 베이에 모두 분포했다(2~6대, 이용자 행동도 함께 반영된 실제 운영 상태). 정적 파일 6개가 빌드와 일치했고, 미보유 분홍 방진복 착용은 정상적으로 구매 필요 안내를 반환했다. 운영 검증에서 구매/기록 초기화는 수행하지 않았고 검증 계정 지갑이 동일했다.

# 말풍선 3글자 제한

사용자가 긴 대화를 막기 위해 한 번에 보낼 수 있는 내용을 20자에서 3자로 줄여 달라고 요청했다.

- 운영자를 포함한 모든 계정에 동일하게 최대 3글자를 적용한다. 구버전 운영자 명령도 예외가 없다.
- 입력 안내와 카운터는 3자를 기준으로 표시하며 초과 시 보내기를 비활성화한다. 직접 전송하거나 구버전 화면을 사용해도 서버가 거부한다.
- 기존 한글 NFC 정규화와 눈에 보이는 글자 단위의 이모지 계산, 한글 입력 중 Enter 처리, 공백 정리를 유지한다. 내부 공백과 문장부호도 한 글자씩 센다.
- 8초 표시, 각자 자기 말풍선만 교체, 퇴장/만료 시 삭제는 그대로다. 대화 내용은 저장하지 않는다.
- 계정·칩·구매품·게임 기록, 카트 끌기/탑승 시야, 기존 카메라와 조이스틱은 변경하지 않는다.

## 검증

- 기존 말풍선 검사 7개를 새 3자 경계로 맞춰 모두 통과했다. 3자 허용/4자 거부, 일반/운영자 명령, 독립 표시·만료, HTTP 프레임 합치기와 기록 보존을 확인했다.
- DOM 모형에서 안내/카운터, 3자 전송, 4자 이상과 직접 submit 거부, 한글 조합 중 전송 방지 및 복합 이모지 계산을 확인했다.
- 격리한 실제 Worker에서 WebSocket/HTTP 이용자와 운영자 명령의 3자 전송·4자 차단, 동시 표시·독립 만료·재접속 시 이력 없음, 지갑 보존을 확인했다.
- 구문 검사와 배포 파일 빌드를 완료했다. 실제 iPhone 시각 검수는 하지 않았다.

검수·배포 자료는 `outputs/speech-limit-3-release/`에 있다. 배포 여부는 해당 폴더의 `completed.json`, `verification.json`, `recovery.json`으로 확인하며 완료 실행기는 다시 실행하지 않는다.

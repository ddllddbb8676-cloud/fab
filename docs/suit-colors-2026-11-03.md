# 분홍·파랑·초록 방진복 — 2026-11-03

사용자가 실제 방진복 색상을 찾아 파랑과 초록 방진복을 각각 50칩에 추가하도록 요청했다. 후속 요청에 따라 협력사라는 명칭은 사용하지 않고 세 상품을 아래처럼 표시한다.

## 색상 참고

[Blaston 제조사 제품 안내](https://www.fact-link.com/mem_content.php?mem=00006192&page=00016043&pl=en)의 BSC-12T01 / BSC-11T01 색상별 실제 제품 사진을 확인했다. [Blue 사진](https://www.fact-link.com/home/blaston-th/00006192-00038763.jpg)의 연한 하늘색과 [Green 사진](https://www.fact-link.com/home/blaston-th/00006192-00038764.jpg)의 연한 민트 계열 초록을 참고했다. 위 HEX 값은 사진을 보고 게임용으로 정한 근사색이며 제조사가 보증한 원단 색상 코드나 실물 측색 값이 아니다. 제조사 사진은 참고 자료로만 사용하고 게임에는 포함하지 않았다.

## 동작

- 기존 분홍 방진복은 상품 ID·가격·색상을 유지하고 이름만 변경한다. 이전 구매자가 다시 살 필요가 없다.
- 파랑·초록은 기존 방진복 재질의 색상만 바꾸므로 새로운 모델이나 텍스처 다운로드가 없다.
- 상점 아이콘, 본인 캐릭터, 다른 이용자의 일반/먼 거리 표시 모두 공통 색상 값을 사용한다. 기존 기본/검정 아이콘의 시인성 색상과 안전팀 역할 색상은 유지한다.
- 상점은 기본 무료 → 분홍/파랑/초록 각 50 → 검정 10,000칩 순으로 정렬된다. 무료 시착, 보유품만 보기, 구매 후 착용은 기존 흐름을 사용한다.
- 사용자 ID·닉네임·기록·칩·기존 보유품과 조작 방식은 유지한다.

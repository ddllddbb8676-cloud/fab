# 무빙워크 우측통행과 카트 회수 정체 수정

## 변경

- 입구에서 팹 안쪽(-Z)을 볼 때 오른쪽(+X)은 안쪽으로, 왼쪽(-X)은 입구로 이동한다. 같은 lane 정의를 쓰는 이동·바닥 화살표·전체보기·지도·서버 카트 판정이 함께 바뀐다. 2배 속도와 카메라/조이스틱은 유지한다.
- 운영 상태를 읽기 전용으로 확인한 결과 두 카트는 삭제되지 않았으며, 사용 중이 아닌 두 카트가 입구에서 각각 약 102m/50m 떨어진 곳에 있었다. 당시 이벤트는 없었다.
- 해당 두 위치를 격리 환경에서 재현했다. NPC가 손잡이까지 간 뒤 좁은 자리에서 회전하지 못해 8초 후 포기하고, 120초 뒤 같은 일을 반복했다.
- 회전이 막히면 현재 카트 축 방향으로 먼저 조금 이동해 여유 공간을 확보하고 경로를 다시 잡는다. 최대 4m 안에서 카트 전체와 손잡이의 충돌 및 회전 여유를 확인한다. 계획은 막혔을 때 한 번만 수행하고 실제 이동은 기존 NPC 속도로 한다.
- 사람이 길을 막으면 기다린다. 이용/탑승 중 카트, 가까운 사용자, 황금 FOUP, 이벤트 중 회수 제외 조건과 기존 회수/입고 동작은 유지한다. FOUP ID·개인 기록·칩을 변경하지 않는다.

## 검증

- 관련 기존/회귀 검사 30개 통과: 양방향 2배 속도, 카메라 유지, 카트 4개 적재/2명 탑승, 두 실제 정체 위치 탈출, 충돌/순간 이동 없음, 동일 FOUP 4개 입고, 사용자 앞 대기, 이벤트 회수 차단.
- 격리한 재현에서 두 카트 모두 홈 복귀와 4개 입고를 완료했다. 당시 좌표/방향만 사용했고 실제 계정이나 운영 FOUP을 조작하지 않았다.
- 실제 iPhone 검수는 하지 않았다.

배포 완료 및 공개 파일/기존 검증 계정 보존 확인은 `outputs/walkway-cart-return-release/{completed,verification,recovery}.json`을 기준으로 한다. 완료 실행기는 다시 실행하지 않는다.

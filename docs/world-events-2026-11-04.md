# 황금 FOUP 찾기 / 돌발 베이 뿌시기

사용자가 두 이벤트를 지금 구현·배포하도록 승인했다. 아래 규칙은 마지막 후속 요청까지 포함한다. 배포 완료 여부와 운영 버전은 문서 마지막의 실제 검증 결과 및 `outputs/world-events-release/completed.json`으로 확인한다.

## 규칙

- 황금 FOUP: 한국 시간 08·12·16·20시, 슬롯당 10분. 모든 접속자가 공유하는 황금 FOUP 20개를 18개 베이 통로에 분산한다. 스토커 IN 입고 +200칩, 깨뜨리는 던지기 +50칩, 청소 완료 +10칩. 일반 FOUP의 +1/+2와 중복 지급하지 않는다.
- 던지기 보상은 기존 FOUP과 동일하게 서버가 파손을 확정하는 던지기를 접수할 때 지급한다. 중간 서버 재시작에도 파손 상태로 복구해 다시 받을 수 없다. 내려놓기·접속 종료에는 보상이 없다.
- 입고한 황금 FOUP은 회수 처리하므로 OUT으로 다시 꺼내 보상을 반복할 수 없다. 제한시간 종료 후 미완료 FOUP/잔해는 일반 FOUP으로 남으며 들고 있던 물건을 삭제하지 않는다.
- 돌발 베이: 실제 연결 계정 15개 이상이고 직전 시작부터 2시간이 지난 경우 1분 예고를 시작한다. NPC와 기존 검증 계정만 제외하고 운영자·사람 안전팀은 포함한다. 공지 후 인원이 줄더라도 이미 예고한 도전은 유지한다.
- 준비 중에는 대상 베이 20대를 전부 복구하고 EMO 파괴를 차단한다. 3·2·1 → 시작 신호부터 서버 시각 기준 정확히 60초. 종료 시각과 같은 시각의 조작은 시간 초과다.
- 초기 버전은 가까운 안전팀 NPC 3명을 보냈으나 사용자의 난이도 조정 요청으로 변경한다. 준비·도전 중 안전팀 NPC 4명 모두 해당 베이의 이동·추격·붙잡기에서 제외한다. 사람 안전팀은 기존 역할을 유지한다. 운영자 시작 버튼과 함께 반영하며 최종 배포 상태는 `manual-events-2026-11-04.md`를 확인한다.
- 일반 파괴/수리 NPC는 준비·진행 및 성공 장면 동안 대상 베이 장비를 건드리지 않는다. 베이 앞 이동은 서버가 확인한 이벤트에 한해서만 제공하며 목적 좌표를 클라이언트가 지정할 수 없다. 패널티·아이디·기록·지갑을 유지한다. OHT에서 내리고 FOUP을 내려놓은 뒤 이용한다.
- 60초 내 0대가 되면 그 순간 연결된 실제 계정 모두에게 +200칩. 참여 여부와 관계없으며 검증 계정·NPC는 받지 않는다. 일반 장비 파괴 +5칩은 그대로다.
- 성공 시 개인 지갑의 지급 확인 및 마지막 장비 붕괴 완료를 기다린 뒤 **베이 뿌시기 성공! +200칩 적립**을 크게 표시한다. 효과음 설정을 따르는 짤랑 소리와 함께 대상 베이 탑뷰를 3초 보여주고 원래 시점으로 복귀한다. 이동·시점 선택으로 화면 연출을 중단할 수 있다.
- 황금 FOUP 진행 중에는 베이 예고/도전을 새로 열지 않는다. 황금 FOUP 시작까지 2분 미만 남은 경우에도 예고를 보류하므로 1분 준비 + 60초 도전이 정시 황금 이벤트와 겹치지 않는다. 종료 후 인원·대기 조건을 다시 확인한다.

## 저장·호환·부하

- `world:events:v1`에 슬롯과 진행 단계·서버 마감·다음 베이 가능 시각만 저장한다. 저장된 개인 ID·닉네임·기존 기록·구매품은 바꾸지 않는다.
- 이벤트 완료 상태와 지급 지갑은 기존 프로필 저장 큐에서 동일 `storage.put` 배치로 확정하고 나서 방송한다. 기존 일반 정원 + 운영자에서도 128개 원자 배치 한도 이내다. 지갑의 `lastEventRewardId`가 같은 지급의 재실행을 추가 차단한다.
- FOUP은 기존 유휴 ID를 재사용하며 체크포인트 v1 행은 그대로 유지한다. 선택적인 `golden` 메타데이터를 덧붙여 구버전에서 일반 물건으로 안전하게 읽힌다. 재접속·재시작은 새 20개를 중복 생성하지 않는다.
- 기존 50ms 룸 틱과 5Hz 방송을 사용한다. 별도 외부 조회·예약 작업·전체 장비 경로 계산을 추가하지 않는다. NPC 경로 계산은 기존 틱당 한 명 제한을 유지한다.
- 황금 표시용 빛원을 추가하지 않는다. 기존 FOUP 인스턴스 색은 달라졌을 때만 갱신하며 작은 표시 최대 20개를 두 개의 인스턴스 드로로 처리한다. 평소에는 표시하지 않는다.
- 숫자 카운트다운은 받은 서버 시각을 기준으로 브라우저에서 표시하며 초가 달라질 때만 DOM을 바꾼다. 재접속/늦은 입장에는 과거 성공 연출을 반복하지 않는다. 사진모드에서는 이벤트 UI도 숨긴다.
- 접속·조이스틱·기존 카메라 리그를 대체하지 않는다. 탑뷰는 렌더링할 때만 잠깐 덮어씌우고 매 프레임 기존 카메라를 복구한다. 사진이나 개인 행동 로그를 새로 저장하지 않는다.
- 성장 분석의 칩 수입 출처에 이벤트 네 가지를 추가한다. 기존 날짜 버킷에 새 필드가 없어도 0부터 안전하게 누적한다. 분석은 별도 FabAnalytics DO에 비동기 전송하는 기존 방식을 유지한다.
